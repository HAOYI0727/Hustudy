## 2. 背景、问题与目标

大学生常通过课件、教材摘录、个人笔记和练习题进行学习。Hustudy 计划解决资料定位、笔记来源关联、基于本课程的解释与练习组织问题。

下列问题原为需求假设，现获得用户提供记录I1的定性支持。记录原文见 [AI记录第9节](Hustudy_AI_collaboration_and_verification.md#interview-source)；作者已补2026-10-13、5位受访者及编号对应；作者已记录五位受访者均同意将回答用于课程提交，小样本不能推断全体学生的需求：资料散落不同文件；笔记难找原文；通用 AI 的回答未必符合授课范围；期末缺少满足本课程蓝图的练习。

目标不是以功能数量作为效果证明，而是让学生从阅读到复习走通可追溯闭环。

首版服务一个小规模课程资料与历年试卷集合，记录定位时间、引用有效性、出题约束满足率与试用完成情况。

## 4. 输入、输出和部署边界

| 对象 | 首版输入 | 首版输出与限制 |
|---|---|---|
| 资料 | `.pptx`、可提取文本的 `.pdf`、`.docx`、UTF-8 `.md`；每份≤20 MiB | 原件、预览/文本、定位、chunk、处理状态；合计规模见 NFR-01 |
| PPTX | 文本框、可提取表格与标题；解析正文 | 幻灯片编号；支持直接原格式静态预览，转换PDF另作兼容；动画/音视频和图片文字不做语义解析 |
| PDF | 文本型 PDF | PDF 页码从 1 起；扫描无文本提示不支持 OCR；加密 PDF 提示先解密 |
| DOCX | 标题、正文段落、表格 | 版本内 block 序号/标题定位；转换 PDF 仅提供预览，不伪造原 Word 页码；正文外文本框、未接受/拒绝的修订和不可提取公式均显示“未保证完整提取，需人工核对”；人工补录内容另存并保留原件 |
| 图片 | PNG/JPEG/WebP，每张≤10 MiB，说明与来源 | 图片附件、UUID 引用、嵌入与反链；正文识别属于 OCR/人工转录能力 |
| 真题 | 支持格式的试卷、可选答案、年份/卷别/来源 | 拆题草稿、人工校正、主次考点映射、已确认样本统计、蓝图提议 |
| Markdown | 文本、标题、普通链接 | 保留源文本，按标题定位；引用偏移采用Unicode字符序号，从0开始、左闭右开，针对不可变原文而非检索token，HTML 必须清洗 |
| 笔记 | Markdown、标签、笔记 UUID 链接、结构化文档引用 | 渲染预览、反链、保存 revision、Markdown 导出；导出引用说明不保证脱离软件仍可回源 |
| AI 请求 | 提问、限定课程/资料、输出类型、模式 | 回答/摘要、引用与状态；JSON schema 校验；不承诺支持资料图片理解 |
| 蓝图 | 章节题数、题型题数/分值、难度标签、时长 | 约束验证、草稿试卷、审阅记录；总题数 1–50，时长 1–180 分钟 |
| 作答 | 选择/判断/简答答案、保存序号 | 服务端保存、提交时间、规则分/建议分、错题；建议分可人工修正 |
| 备份 | 当前账户导出的版本化 ZIP | JSON 清单与业务数据、原件、笔记、引用、作答和复习任务；不含 API 密钥 |

运行环境假设：个人电脑本地部署，桌面浏览器；阅读、笔记、关键词检索无需远程模型；真实 AI 依赖服务、网络和预算。Linux/Docker 参考环境可用于演示，但平台支持范围应由实际构建测试决定。

## 7. 业务规则与关键异常

BR-01：只有当前用户有权限且未删除的资料可进入检索上下文。资料内的“忽略指令”等文字视为内容，不改变系统权限和规则。

BR-02：文档和笔记链接用 UUID；文档引用定位到不可变版本。笔记改名不破坏链接；文档更新不覆盖旧版；用户删除后保留失效占位而不继续提供私有文件。

BR-03：个人笔记不是自动可信知识。未审阅 AI 草稿不能作为出题唯一依据；原始课程资料与人工审阅笔记的来源类型需可区分。

BR-04：蓝图每题有一个主章节；跨章节内容可附标签，但 P0 主章节配额只按主章节计数。题型数量和主章节数量分别加总为总题数；分值按题型固定正整数。

BR-05：模拟卷先生成草稿再审阅。参考样卷只用于用户指定风格和统计蓝图，不承诺重现教师出题规律。生成不足明确失败，不无声放宽约束。

BR-06：考试截止使用服务器 UTC 时间计算，再按用户时区显示。刷新页面不能延长考试；到时界面触发提交，断网时服务器仍拒绝继续改答案，重连后可提交已有保存内容。倒计时是否归零不由本地时钟决定。

BR-07：试卷题目和答案快照不可随重生成改变。开始后修改原蓝图不改变当前作答；提交后禁止重复覆盖。简答建议分修正保留原值与修改记录。

BR-08：备份不包含 API 密钥。恢复只允许空账户，导入时将所有者映射到当前账户；持久 UUID 不变，存在冲突立即拒绝。校验和暂存全部成功后才提交业务数据，重新建立搜索索引。

| 故障 | 用户可观察行为 | 数据处理 |
|---|---|---|
| 旧 `.ppt`、扫描/加密 PDF | 显示转换或解密提示 | 不假装解析成功，不产生空索引 |
| PPTX 转 PDF 失败 | 原格式仍可打开；兼容预览显示错误，可回文本 | 保留成功解析内容，预览任务可重试 |
| 来源缺失 | 显示不足或引用失效 | 不编造出处、不重新指向其他文件 |
| 模型限流/超时/坏 JSON | 显示任务失败，可重试 | 不写入半套“成功试卷” |
| 同时编辑笔记 | 显示版本冲突和两份内容 | 不丢弃未提交本地正文 |
| 考试断网/刷新 | 显示最后保存时间，重连恢复 | 服务端 deadline 保持不变 |
| 磁盘不足/备份坏文件 | 说明失败且保留原有数据 | 临时文件清理、事务回滚 |

## 11. 业务补充与实施边界

BR-09 知识点标签来源：教师标注/大纲、已确认真题观察、AI 建议分别存储和显示。AI 判断的“重点”只能说有辅助学习价值，不能标为教师要求；疑似考点不能显示成确定预测。

BR-10 真题可信度：试卷与答案由用户提供，来源、年份、卷别可未知；确认题目结构不等于确认试卷官方真实性。AI 参考答案和用户提供答案独立保存，来源不明不得默认标标准答案。

BR-11 正式统计输入：只有已确认拆题和已确认主考点映射的叶子计分题进入正式考点统计；未确认题、未映射题的数量及分值单列。题型整体统计可按已确认拆题计算，不要求先完成全部映射，两个报告必须显示各自分母。

BR-12 去重与年份：文件 hash 相同直接提示已有材料；不同扫描件或合并文件是否同一试卷由用户确认 canonical_paper_id。统计只取当前活动的已确认版本。同一年 A/B 卷可计两份独立卷，但年份出现率仍只计一个年份。

BR-13 分值：父题和子题不得重复累计。分值统计按主考点或用户确认的分配计算；P0 用主考点，次要标签只计涉及次数。未知分值不置零；未知年份不猜年份；总分与分母为空显示不可计算。

BR-14 报告变更：考点改名/合并、真题修订或来源被删后，历史报告保留原快照且标 STALE，不将旧报告伪装最新。新报告重算；已完成的模拟卷与答案不改变。

BR-15 扫描件与补录：P0 支持扫描 PDF 的原页查看及人工补录题目，自动识别为 P1 OCR。人工补录保存独立转录文本、来源页与确认记录，引用标“人工转录”，不声称文字是解析器直接提取；图表、公式需对照原页核实后才能用于正式出题。

BR-16 题型范围：P0 自动规则评分只支持单选和判断；计算、推导等可作为简答子类型，用 rubric 和人工核实，不承诺自动判分精确。多选、填空等按工期扩展；用户原卷中的不支持题型保留原文并显示能力范围，不丢弃。

BR-17 补弱：依据当前用户的真实作答与确认错因推荐补练。没有数据时允许用户自选知识点，状态为未评测；不把未阅读、未记笔记或未点击解释直接当“没掌握”。

BR-18 生成预算：大资料按章、试卷按页/题分批处理，保存中间草稿并显示数量；单 AI 任务受 NFR-07 预算约束，超时可从已完成步骤续跑。不以无限后台重试实现成功，重试须区分已有有效结果与失败步骤。

## 附录B：字段级接口契约

这是需求层接口设计，不宣称现有后端已经实现全部字段。API统一前缀 `/api/v1`，UUID为持久ID，时间为带时区ISO 8601；用户身份由登录态取得，不信任请求传入的user_id。任务创建返回202；参数无效422；无权限对象按404；版本冲突409。错误形态为 `{"error":{"code":"...","message":"...","details":{},"request_id":"..."}}`。

机器可读定义见 [JSON Schema](Hustudy_requirements.md#schema)，采用 Draft 2020-12。schema只负责结构；授权、摘录存在性和学科正确性不能靠JSON Schema验证。下表中必填对象不允许额外字段；省略与null不同，只有声明nullable的字段可为null。

### 1. 请求及任务

| 字段 | 类型/必填 | 约束/用途 |
|---|---|---|
| course_id | UUID/是 | 必须属于当前账户 |
| scope_version_ids | UUID数组/是 | 1–20个，不重复，均为当前课程有效可检索版本 |
| query | string/是 | 1–4000字符；当输出教学报告时为学习目标说明 |
| output_type | enum/是 | answer 或 study_report |
| model_mode | enum/是 | mock 或 remote，不能由前端标识改变实际Provider |
| consent_id | UUID或null/是 | remote必须为已确认且绑定实际片段hash的服务端记录；mock为null |
| prompt_version | string/是 | 1–64字符，必须为服务端允许的版本 |

先解析授权范围和检索片段，再向用户展示实际待发送片段，确认后创建consent_id。范围或片段hash改变必须重新确认；过期/拒绝确认不得调用远程模型。密钥只在后端配置。

任务响应包含 job_id(UUID)、status(QUEUED/RUNNING/SUCCEEDED/FAILED/CANCELLED)、scope_version_ids、processed_count(≥0)、total_count(≥0)、step(string)、error(错误对象或null)、result_id(UUID或null)。processed_count≤total_count；进度是工作单元数，不是模型正确率。所有耗时分析/生成入队，失败保留步骤但不得保存半套成功试卷。缓存键至少包含user_id、course_id、范围版本及内容hash、query、output_type、prompt_version、实际Provider/模型及模式、生成约束；命中时重新检查授权和来源是否已删除，不能因同一资料而复用不同问题的答案。

### 2. Citation

| 字段 | 类型/必填 | 约束 |
|---|---|---|
| version_id / chunk_id | UUID/是 | chunk必须属于该不可变版本 |
| locator | object/是 | type为slide/page/heading/docx_block；数值定位从1开始，heading为非空标题 |
| quote | string/是 | 1–8000字符，须存在于对应原文或已确认转录 |
| quote_hash | string/是 | 原样quote UTF-8字节的SHA-256，小写64位hex，不先做空格归一 |
| start_offset / end_offset | integer/是 | chunk原文Unicode字符序号，0起、左闭右开；end>start；正文切片等于quote |
| source_kind | enum/是 | original 或 manual_transcript；后者须有已确认转录记录与原页 |
| availability | enum/是 | active 或 unavailable；由服务端决定 |

删除来源后引用元数据可保留，availability=unavailable；不得据此重新下载文件或发给模型。模型只能选择服务端提供的来源ID和摘录，availability与归属由服务端重新校验。

### 3. AIResult 和 StudyReport

| 对象/字段 | 类型/必填 | 规则 |
|---|---|---|
| AIResult.status | enum/是 | grounded / insufficient_evidence / provider_error |
| AIResult.answer | string或null/是 | grounded时非空，其余为null |
| AIResult.citations | Citation数组/是 | grounded至少1条有效来源；其余为空 |
| AIResult.reason | string或null/是 | 非grounded必须有失败或不足原因 |
| AIResult.model_mode | enum/是 | mock/remote，服务端实际模式 |
| StudyReport.scope_version_ids | UUID数组/是 | 必须与批准范围一致 |

### 5. 校验顺序与可测试反例

1. 校验登录身份、课程/版本/来源有效性；跨账户返回404（TC-01/10/23）。
2. 校验请求结构和remote发送确认；有scope无确认不能调用（TC-10）。
3. 模型响应先解析JSON再执行schema；缺字段、额外字段、非法枚举、类型错误拒绝（TC-12）。
4. 校验引用版本、摘录、offset和hash，以及标签证据；假引用拒绝，不能靠正则补页码（TC-11/22）。
5. 校验题型答案、rubric、蓝图整数配额和总分、题干去重；错答案ID或不足题数都不返回成功（TC-13/14/31）。
6. 在预算内最多修复两轮；仍失败返回provider_error及原因，保留已有笔记与历史结果（TC-12）。
7. 人工对照引用语义和学科答案；JSON合法并不等于内容正确，按NFR-04/13单独测量。
