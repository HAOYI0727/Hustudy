# M4 图片题库与审核改进验收

日期：2026-10-20。用户要求直接修改、验证、保存后关机；不提交或推送。保留此前M4及其他模块工作区修改。本轮用户明确授权图片OCR，覆盖早期“扫描件只人工补录”的范围限制；没有扩展语音、远程识别或AI生成。

## 已实现

- 自动区分仅题目、题目与答案、包含解析、仅答案/解析。支持中文/全角题号、A–D选项、答案/解析/分析/解答/详解标签和明确独立答案区；选项答案只接受显式键或“故选B”等明确结论，不从含糊解析推断。仅题目保留草稿并提示补答案，只有解析不当作有效题干，人工补充后可保存。
- 文档与图片导入分开。选择图片本身不会启动识别，只有显式点击“识别图片文字并拆分题目”才保存图片并入队。单批最多20图、每图10MiB/2000万像素，可调整顺序、移除、选择单栏或每图先左后右双栏，上传失败保留已成功文件，不自动重放；任务后台处理、刷新可恢复查看，失败显式重试。
- 本地RapidOCR行坐标用于按阅读顺序和题号关联原图区域；跨图续题连续解析。完全无题号时暂按每张/每栏一题，不将整批无题号图片混成一道；标明临时序号、空识别区域和需要人工拆合。按原图内容hash与版面去重，重复成功/进行中的批次返回原任务。
- 原图区域仅用于审核，保留图文一起上传的原貌，OCR可能把图中标注写进题干，用户可直接改题干；不宣称自动准确区分所有图形。题目支持独立插图多选上传、移除、说明；也可在完整原图拖框裁取或精调百分比，实时查看裁剪结果。每题最多8图，只有明确核对“不含答案/解析”后可确认入库。题目拆合保留原图与插图但撤销插图审核，必须重新核对。
- 作答快照只带审核后的插图，不带原图区域；服务端实际裁剪像素返回，不以CSS遮挡整张带答案截图。图片读取、编辑、确认、抽题均检查M1有效归属与课程；删除图片显示不可用，历史题目快照不被题库编辑重写。账户备份校验图像UUID、裁剪区域、课程与识别任务关系，恢复后原图/插图仍可查看。
- 审核支持标题行直接勾选（无需逐题展开）、全选本页、批量标签、单题/批量删除和按题库统一确认。删除保留原题历史，退出当前题库/统计/抽题，不破坏已提交作答；revision冲突整批拒绝，进行中考试禁止删除/改题。未保存校正阻止直接确认题库。
- 勾选框22px、点击区域至少44px，标签卡片可整行选择，卡片/状态/危险动作/导入方式复用原有主题；复杂元数据按需展开。电脑与390宽度自动重排，AI练习直接入口同样加载控件样式。

## 技术与数据边界

新增bank_parser、bank_images、bank_ocr服务及BANK_OCR worker；复用M1图片接口与授权适配器，只在共享worker入口添加任务派发，不改M1解析器或M3识别任务。JSON沿用0019/0020，无新表或迁移。OCR单批子进程最多360秒，租约480秒，过期显式失败，不自动重试；拒绝迟到或撤权写入。

本机项目.venv已安装`backend/requirements-bank-ocr.lock`；其他机器安装该可选锁并重启后端与worker。无语音依赖、模型密钥或任务时模型下载，不发送题目给远程模型。官方版本API和wheel许可核对见[第三方记录](../third_party.md)，完整声明保存在docs/licenses/m4-ocr。

## 使用步骤与限制

重启后端与worker并刷新前端，进入“真题与模拟卷→上传与校正题库”。先设置统一标签（可选），选择文档或图片；图片调整顺序/版面后显式识别。展开需校正题目，对照原图修改误识别的图中文字、题型/答案/唯一性；需要插图则独立上传或拖框裁取，勾选插图审核并保存。标题行勾选可批量标签/删除；全部校正保存后按题库统一确认，再按标签抽题。

扫描PDF可先转PNG/JPEG再使用此入口，或沿用M1人工转录；本轮没有改扫描PDF解析器。手写、复杂公式、无题号的多题混排、跨栏图形及图片中存在独立答案区仍需逐题核对，不能据少量自制样例宣称通用准确率。多空唯一性仍需用户明确设置，缺答案的自动批改题目不允许直接确认。不代记真人试用、实机Safari、学科答案准确率或成员签收。
