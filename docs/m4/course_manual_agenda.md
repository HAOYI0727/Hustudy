# 课程手动日程

首页当前课程日程支持添加和删除日程，内容最多240字，使用日历选择日期。通过当前账户时区与完成状态划分到期、逾期、今天、未来、已完成及全部待办。用户可标记完成或恢复待办。

复用 ReviewTask，增加可空 course_id 外键与0023迁移。旧错题计划仍沿错题关系确定课程，手动日程按本人有效课程关联。新增状态更新携带 expected_status，冲突返回409。删除只移除日程记录。

新增接口复用 POST /review-tasks 的 course_id、title、due_date，补 PATCH /review-tasks/{id}/status 与 DELETE /review-tasks/{id}。课程及账户归属在服务端验证。界面显式提交，切换课程拒绝迟到响应，日程变更后重新读取分类统计。

课程下拉新建操作在页面导航与滚动复位后展开表单、滚动到名称输入框并聚焦，消费一次定位请求。

隔离后端日程回归7项通过，前端TypeScript检查通过。浏览器交互仍由实际操作核对。
