# 独立题库文件库与便捷删除（2026-10-20）

## 使用

- 上传PDF/ZIP/文档后，原件进入题库页的“题库文件库”，不进入资料阅读、资料分页/搜索或资料导出。保留扫描PDF、图片识别和AI知识点归类流程。
- 每道题标题右侧有“删除本题”，不用展开详情、逐题确认。勾选后“删除所选”也可一次处理；页面出现对应“撤销删除”按钮。
- 每份题库提供“查看题目（N）”“删除整份题库”，整份只确认一次，可撤销。删除题目保留原件、原图和既有作答/试卷；撤销后恢复草稿，请重新确认题库。
- 本次页面保留最近10次撤销入口；刷新后入口清空，后台软删除记录仍保留。它不是永久删除或完整回收站。
- 旧版已放入资料阅读的题目原件会在文件库标为“旧资料来源”，点击“移入题库文件库”即可分开。由于旧数据没有可靠导入用途标记，不会自动搬动课程资料。移动保持原UUID、版本和引用，旧作答不重写。
- 在文件库“下载原件”查看PDF/源文件；题目中的资料引用若属于题库文件，会引导到题库原件，普通课程资料仍可回源阅读。

## 存储与共享边界

继续使用项目统一SQLite与账户授权。0021_bank_library给Document增加library_scope（material/question_bank），新题库原件使用独立question_bank存储子目录、专用上传/列表接口与独立界面。复用原有不可变版本、解析、OCR/Asset和M1只读授权；既有资料默认material，迁移不猜测改旧数据。

同内容跨两个库不共享Document身份；同库重复上传仍复用。资料列表/分页/任务列表/关键词检索/资料导出排除question_bank，派生PDF原页也排除资料导出。完整账户备份包含两个库，标记0021；0012–0020旧备份缺少scope时补material，其他校验不放宽。

已授权UUID的读取接口保持兼容，避免破坏已有笔记/资料引用；它不将题库重新加入资料目录。题库页回源引导到题库文件库下载原件。

## 删除边界

单题/批量使用现有SUPERSEDED加removed_by_user软删除标记，增加revision，撤销核对全部题目revision，整批失败不部分写入；拆合父题未标记人为删除，不可通过撤销复活。

整份删除要求metadata revision与全部当前题目(id,revision)集合hash一致，5000题上限；软删除并隐藏题库，取消BANK_OCR/BANK_EXTRACT任务、清除租约。撤销检查整份删除时的题目集合/修订，允许空题库恢复；不会重发取消的任务。删除后的OCR/AI任务从任务列表隐藏，避免刷新后自动展示已删除题库。进行中考试仍禁止查看答案/管理题库，完成后可删除，已提交快照保留。

无真实模型调用、提交推送或成员代签。迁移仅记录本轮实现/测试，不视为其他成员人工评审签收。
