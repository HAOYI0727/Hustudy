## 使用入口与能力

笔记编辑器点 Σ 或 Ctrl/Cmd+Shift+M 打开“公式编辑器”。桌面左侧是工具箱，右侧是源码、参数与即时预览；小屏先显示正在编写的内容，向下滚动使用工具箱，确认按钮保留在窗口底部。

- **符号与模板**：357 项，16 个分类，默认显示 8 个常用结构；名称、符号和 LaTeX 命令均可搜索。搜索覆盖全部分类，清空后回到所选分类，超过60项可继续展开。
- **嵌套参数**：点击分数后出现分子/分母按钮；定位分子再点击根号会组成嵌套公式，保留分母和前后文。点击参数或 Alt+↑/↓逐项定位，参数文字直接在源码中修改；内部位置随输入更新，不把参数标记写入笔记。
- **窗口内撤销/重做**：箭头按钮、Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y；最多80步，包含源码与排版切换。正文仍只有确认后改变，取消保留原正文。
- **矩阵 / 多行**：11种结构，圆/方/花括号矩阵、单/双竖线、无括号、分段、方程组、对齐、居中多行、自定列对齐/增广矩阵。1–8行列、逐格填写、即时预览，Tab切格；缩小行列暂时隐藏内容，再扩大可恢复。切换结构保留该结构各自的格子内容。空白项写 `{}`，禁止在单格用顶层 `&` 或 `\\` 偷加行列；嵌套矩阵允许。生成器插入后仍可修改源码。
- **语法速查**：12节本地说明与可插入示例，涵盖嵌套、分组、中文/单位、括号、微积分、矩阵、多行、字体、颜色、Markdown边界与错误排查，无需跳到外部网页查基本写法。

仍保留行内/独立公式、原公式再编辑、实时语法提示、正文撤销、分屏、保存/导出、登录失效恢复和取消保护。复杂多行模板与表格结构自动选择独立公式；普通结构沿用当前模式。模板内重复变量并非联动变量，修改示例时需逐处核对。

## 手动复验建议

1. 空公式插入“分数”，分子改为 `x+1`；重新选中分子并点“根号”，分母改为 `n+1`。预览应为根式分式，参数按钮仍能定位；试一次撤销/重做再确认。
2. 切到希腊字母分类，再搜索“偏导数”或 `\alpha`，应能跨分类找到；查看关系、字体、上下括号、颜色和完整公式示例。
3. “矩阵 / 多行”选择自定列对齐，设3行3列、`cc|r`，填分数或字母。缩小再扩大行列应保留内容；插入、保存、刷新后增广分隔线仍在。分段函数的右列用 `\text{其他}` 验证中文条件。
4. 打开语法速查，展开多行推导，插入示例并继续修改。取消应不改变正文；重新打开已有公式修改后确认应替换原公式。
5. 手机宽度检查源码、预览、搜索、表格横向局部滚动和底部确认。导出Markdown后检查 `$...$` / `$$...$$` 源码保留。

## 边界与交接

共享约定已在功能修改前写入 [AGENTS](../../AGENTS.md)、[契约](../contracts.md#m3-editor-math-02) 和 [交接](../../collaboration/handoff.md)。无新增依赖、后端API、迁移和存储格式变化；继续使用本地KaTeX0.19.0，许可构建流程保持。

这是项目内数学公式编写工作区，支持直接编辑渲染器支持的数学LaTeX；并非完整TeX文档编译器。`documentclass`、`usepackage`、TikZ、任意宏包和外部文件不支持；单公式4000字符、宏展开与尺寸仍受限。表格生成器之外的更大结构可手写源码并受同一预算约束。没有加入手写公式识别、排版区域直接拖拽或外部数学服务。已持久化公式重新打开时保留源码，参数按钮由本次插入模板生成，不从任意旧源码反推参数。
