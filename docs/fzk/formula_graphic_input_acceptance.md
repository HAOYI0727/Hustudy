## 输入方式

- **图形符号面板**：常用、希腊、关系、集合逻辑、箭头五组，按钮直接显示数学符号；中文名称和命令放在悬浮说明及无障碍名称中。手机采用面板内部横向滚动，触屏热区至少44px。
- **12个结构图形**：分数、根号、高次根号、上下标、幂与下标、求和、积分、括号、绝对值、向量和矩阵。图标用空框表示位置，点击后沿用可编辑模板；选中的内容进入第一个参数，可继续嵌套。
- **填写参数**：图形结构自动打开字段，分数的分子/分母上下排列；其他字段并排显示。修改字段即时同步源码和预览，Tab切换字段，Alt+↑/↓和上一项/下一项定位；可以随时返回源码。
- **保持插入位置**：从字段点符号后仍回到该字段的光标，连续点符号可连续输入。“移到公式末尾”明确退出参数，方便接着写加号或下一项。
- **恢复已有结构**：重新打开已有公式时识别明确的分数、根式、带花括号的上下标、修饰等字段；手写源码后可点“识别结构”。识别只产生位置索引，不改写源码。
- **最近使用**：折叠区提供本次窗口最近12个符号/模板；只保存静态ID，不保存公式内容，不写浏览器持久存储。357项分类库、搜索、11类矩阵生成和本地速查继续可用。

参考 [AxMath官方使用手册](https://www.axsoft.co/AxMath_Help.pdf) 的分类符号面板、结构子字段与键盘操作，以及 [界面说明](https://axmath.gitbooks.io/axmath-docs-en/content/2._main_interface.html) 的符号区/源码区分工。这里只借鉴交互，自行编写UI与字段逻辑；图形由已有KaTeX与CSS生成，没有复制商业软件代码或素材，没有安装AxMath或新增依赖。

## 复验步骤

1. 打开 Σ，点图形“分数”，在分子填 `x+1`，将光标放末尾后连续点 ±、α。应插入分子末尾且保持焦点，Tab可以进入分母。
2. 分母填 `n+1`；选中分子内容，点图形“根号”，应组成嵌套根式分数。修改被开方数字段后撤销/重做，分母应保持不变。
3. 点“移到公式末尾”，再点 +、π，确认它们位于整个分式后。保存、刷新、重新打开公式并点“填写参数”，修改根号里的内容，其他部分应保持。
4. 输入不完整的根号，字段仍可继续修正，错误未修复前不能确认；未知宏和不支持写法保留原源码并提示。取消不改变正文。
5. 在手机宽度切换五个符号组、横向滚动面板、使用结构字段和底部确认；旧分类搜索、矩阵生成、公式导出与登录恢复继续复验。

## 限制与交接

结构识别是保守的编辑辅助，不是完整TeX语义解析器。只恢复明确且平衡的参数，跳过文本/注释/环境名称、未知宏参数；扫描遇到宏定义时不恢复字段。不完整结构仍可在源码或已有字段内修正；`\frac12` 等省略花括号的写法可渲染，但不自动改写成字段。最多80个恢复字段，扫描与渲染长度/深度受限。公式仍为LaTeX源码，预览区域暂不提供直接拖拽排版或自动计算。
