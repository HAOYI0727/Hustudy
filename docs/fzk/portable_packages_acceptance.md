# 标准数据包：导入、导出与课程合并

## 操作入口

- 课程总览：“导入课程包”，或课程卡片上的“导出课程包”。导入课程包时选择“新建课程”或“合并到已有课程”。可以依次把多个来源包追加到同一门课程。
- 知识笔记：“标准数据包”中的“导入 ZIP”“导出当前范围”。选中文件夹后，也可“导入到此文件夹”“导出此文件夹”。
- 两种操作都先选择条目，再点击“预览所选内容”，核对最终数量、关联依赖和省略说明，最后明确确认。支持类别全选、单条选择、名称查找及分页。

课程包包含可安全识别的资料原件／版本／片段、笔记／目录／标签／图片／引用、知识标签、题库、组卷配置、试卷及已提交作答／错题／复习任务、已保存学习结果和分析。必须的图片、目录祖先和来源资料会作为依赖列入预览；取消某篇笔记不会因其目录仍被选中而重新导入该笔记。

文件夹包仅包含笔记、目录与范围内引用图片。资料回源、题库和学习记录不随文件夹迁移，界面会说明；需要完整回源时使用课程包。导入到课程根目录时，未归档笔记仍未归档；指定父文件夹时，未归档笔记放入该目录，包内顶层文件夹接在它下面。

课程合并保留目标课程的名称、简介、分类、标签及全部原有内容。新增对象采用新身份，同名笔记／资料并存，同级目录重名追加“导入2”等后缀；不根据名称自动覆盖、去重或合并正文。包内双链和图片指向导入的新副本；未选笔记的链接转为普通文字，避免悄悄跳回原数据。

## 三种ZIP的区别

| 用途 | 选择方式 | 导入条件 |
|---|---|---|
| 普通笔记阅读ZIP | 原“选择笔记导出” | 用Markdown阅读器离线阅读；只有MD及引用图片，不包含课程迁移清单 |
| 标准数据包 | 本轮课程／文件夹入口 | 可自选内容，新建课程、合并已有课程，或导入笔记目录；内含版本化清单和文件 |
| 完整账户备份 | “备份与恢复” | 沿既有空账户恢复规则，保留原身份；不是追加合并 |

标准包用 `manifest.json` 记录目录、标题和关系；文件区的内部标识用于可靠重映射。需要按标题整理并直接阅读的MD文件，继续使用普通笔记阅读ZIP。标准包不接受任意未知ZIP，不能把其他软件的压缩包自动猜成课程。

## 可靠性与边界

- 预览不会创建课程、笔记或其他业务内容。预览和确认绑定内容摘要；来源变化时需要重新预览。确认后的未知响应保留请求身份，可“核对导入结果”并明确重试原请求，成功结果不会重复写入。
- 登录过期停止操作，不自动重发。待核对请求仅保存必要标识、目标与选择到本机当前账户会话，不保存ZIP正文或密钥；退出后可重新登录原账户核对。
- 所有导入业务与成功记录同事务。写文件或提交失败时回滚新对象并清理新文件；已经提交成功但响应丢失时可查回结果。导入不派发模型、识别或学习任务。
- 自动排除任务／远程调用授权／配置密钥／回收站／账户偏好和反馈。跨课程或无法安全保留的依赖明确省略或拒绝，不能冒充完整保存。正在作答的练习及未完成学习过程不作为完成记录迁移；导入分析标为需刷新，已有AI结果为只读历史，不复用调用授权。
- 单包ZIP≤100MiB、展开≤256MiB、清单≤8MiB、成员≤3000、笔记≤2000、业务行≤20000；单资料≤30MiB、图片≤10MiB／2000万像素／单帧。目标目录总数≤500、层级≤6。来源范围与最终包均须符合预算：来源范围超限时先缩小课程／文件夹范围，最终包超限时减少所选内容，不截断。课程包先检查整个课程来源，不能仅靠取消勾选绕过来源预算。
- ZIP全包在写业务前检查路径、重名、类型、长度和SHA-256；拒绝穿越／绝对路径／链接／加密／未声明文件及不合法压缩比。每账户最多10份活动预览，24小时到期，可在界面清理已上传预览。
- 数据库新增0022控制记录迁移，后端启动时自动升级；无新增依赖。原日常内容不参与测试，迁移前沿项目既有流程生成数据库备份。

## 人工复验

1. 总览导入01为新课程；预览时取消一篇笔记后确认，核对只有选中笔记和明确列出的依赖进入课程。
2. 再导入01并选择“合并到已有课程”，或用07合并到第1步课程。核对原课程信息／原正文保持；同名内容并存、目录自动区分。可继续合并其他来源包。
3. 在笔记工作区导入02、03、05至指定课程或目录，分别核对子层级、图片、双链、未归档和空目录。
4. 从总览导出课程包，再导入新课程；从文件夹入口导出范围后再导入。核对普通阅读ZIP入口仍能正常按标题导出MD。
5. 选06确认拒绝；上传正常包后关闭窗口，确认没有创建业务。用“管理已上传的预览”移除无用记录。
6. 保存当前工作，重启后端或等待reload完成再刷新前端。确认浏览器出现新入口后开展复验。自动测试不能代替本人验收。
