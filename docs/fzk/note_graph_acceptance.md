## 使用

在“知识笔记”点击“关系图谱”，查看当前课程的已保存笔记关系。箭头从引用笔记指向被引用笔记；同方向重复引用只显示一条，反向引用仍独立。点击节点或右侧列表仅选择笔记，点击“打开笔记”才进入编辑；有未保存内容时沿用原确认保护。

输入标题并点击“查询”，或选择已关联/孤立筛选后查询。这里的孤立指在完整当前课程内没有有效双链；跨课程链接不计入此图。选择笔记后点击“聚焦关联”，显示它及直接引用/被引用的笔记；“查看全课程”清除聚焦和筛选。编辑器的“引用与关联”也可直接查看当前笔记的关系图谱。

窗口显示已保存关系，未保存的正文修改不计入。标题改名、链接增删或回收笔记后，可以点击“刷新图谱”。默认最多120篇，接口最大200篇、400条关系；超过时明确显示真实数量和截断提示，可缩小标题范围或聚焦。度数表示完整当前课程中的引用/被引用数量，不等于当前画布显示的连线数。

## 实现与边界

- API、字段和作用域以[公共契约](../contracts.md#m3-note-graph-02)及[API](../api.md)为准。服务端在同一SQLite读快照中完成课程权限、元数据投影、去重边、筛选及真实计数；不读取`Note.content`，不逐篇取正文。
- 关系只来自本人、当前有效课程、两端未删除笔记的现有NoteLink；排除自身链接、跨课程、他人或失效对象。返回当前笔记标题，不使用链接中可能过时的标签。
- 窗口按需加载，显式刷新/重试；关闭取消请求并隔离迟到响应，401关闭窗口交给既有重登。选择/浏览不修改笔记、不调用模型。没有新表、迁移或依赖。
- 图形布局为本地确定性排布，保留方向箭头、选中高亮、缩放与键盘列表。标签优先显示选中笔记，自动尝试不同方位和缩略长度，避开圆点、其他标题和画布边界；完整标题始终在列表中。不表示知识相似度、掌握程度或自动语义分析。

## 人工复验

1. 在同一课程准备A、B、C三篇笔记：A引用B，B引用A，C不插入双链。打开图谱，确认A/B双向箭头，C为孤立；重复插入A到B仍是一条方向边。
2. 输入A标题查询，确认只展示匹配笔记，详情仍显示其完整课程关联数；筛选“孤立笔记”确认只显示C。聚焦A应显示A和B，返回全课程后C重新出现。
3. 选择B并点击“打开笔记”，核对正文。改名保存后刷新图谱显示新标题；将B移到回收站后图谱不再显示B及对应边，恢复后刷新再次出现。
4. 暂时清空当前标题（使自动保存等待有效标题），再补充正文并打开图谱，确认草稿提示；选择其他笔记并取消切换，原草稿和窗口均保留。完成后恢复标题并保存。浏览图谱不会主动保存或替换正文。
5. 缩窄窗口或使用手机尺寸，确认搜索、图形、列表、详情均可操作；用Tab/Enter选择列表或图形节点、打开/关闭，焦点可返回入口。后端不可用时显示局部错误，可明确重试。
