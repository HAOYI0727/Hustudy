## 使用

笔记管理中央列表勾选后点击“批量删除”，每批最多200篇，确认后移入回收站；编辑器“删除这篇笔记”同样移入回收站。已有未保存内容时批量操作暂停，单篇删除会明确提示是否放弃草稿。

顶部“回收站”打开账户全部课程的回收站窗口，每页50篇，显示标题、课程、删除时间及计划清理时间，不展开正文。勾选单篇或本页多篇后“恢复所选”或“彻底删除所选”；“清空回收站”针对所有课程和全部分页，确认后执行。与服务器版本不一致时整批拒绝，刷新并重新确认；失败不从界面假移除内容，401/409不自动重放。

恢复保留UUID、标题、正文、标签、图片和资料引用。原文件夹还在则恢复原位置，文件夹已删则未归档；原课程已删或未关联课程时，明确恢复到当前课程未归档目录。恢复后已有UUID双链可再次打开；原资料/图片若已经删除，恢复笔记不会恢复那些来源。彻底删除仅清理笔记及其关系，不删除图库图片和原资料。

“自动清理设置”默认折叠，默认30天，可修改为1–365天整数或关闭；设置作用于整个账户。期限按删除时间加若干个24小时计算，服务端存UTC、界面按浏览器时间显示。修改天数会重算已有回收站期限，缩短期限可能导致旧笔记下一轮清理；保存前提示并确认。关闭会移除已有到期计划，重新启用仍从原删除时间算起。

worker启动时及运行中约每分钟检查一次，每轮最多200篇，繁忙任务期间会延后；离线/后台停止期间不执行，重启后分批处理积压。到期不等于精确整点删除。普通导出和搜索排除回收站；已有ZIP只在其全部来源重新有效后才恢复下载资格。此前已下载文件和完整账户备份不受回收站删除影响。

## 更新后启动

本轮增加0016迁移。先保存编辑区草稿，重启后端和worker，再刷新前端。已有开发数据库启动前由项目数据库初始化逻辑自动生成迁移前备份；不要删除数据库重建。旧deleted记录没有可靠删除日期，从迁移时开始完整保留30天。

后端窗口在工程根目录运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload
```

另开PowerShell，在同一工程根目录启动worker（已有worker先停止旧进程再重启）：

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) 'backend')
.\.venv\Scripts\python.exe -m app.workers.materials
```

不必重新安装依赖。自动清理和ZIP后台导出需要worker运行；关闭终端后它们会暂停。

## 复验步骤

1. 创建两篇临时笔记，添加标签、文件夹、图片及相互双链；中央勾选批量删除。确认列表/普通导出不再包含它们，回收站能看到两篇。
2. 在回收站全选恢复，确认原文件夹、正文、标签、图片与双链仍正常；再删除文件夹已清空的一篇所属目录后恢复，确认笔记出现在未归档。
3. 再删除两篇，回收站只选一篇彻底删除，确认另一篇仍在；取消“清空回收站”应保留内容，重新确认后清空。只用临时笔记验证彻底删除。
4. 展开设置：默认30天；改7天后关闭重开仍为7天；关闭自动清理后各条显示“自动清理已关闭”，重新启用30天后计划时间恢复。缩短期限的确认说明应可见。无需等待真实30天，边界与离线续清通过隔离测试验证。
5. 两个浏览器窗口打开同账户，在一处打开回收站后从另一处再删除一篇；旧窗口“清空”应提示内容已变化且不删除，刷新后可重新确认。未保存草稿期间批量删除按钮应不可用。
