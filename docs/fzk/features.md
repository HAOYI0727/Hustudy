# fzk 功能实现记录

模块：M3 NoteGraph。当前为模板；尚未收到本人提交的功能证据。已有仓库行为和队长辅助改动见 [公共进度](../progress.md) 与 [交接日志](../../collaboration/handoff.md)，不归记为本人贡献。

每完成一个切片追加以下条目：

- 日期、记录者、实际实现者（含 AI 辅助）、任务/需求 ID。
- 分支、commit/PR 或“工作区未提交”；代码文件和允许修改范围。
- 功能与调用/使用入口；输入、输出及失败行为。
- 依赖的公共契约及受影响模块。
- 真实验收命令、环境和输出；未执行项与限制。
- 个人 progress 链接、交接 ID、本人审阅状态。

不另写第二套共享 schema/API；不将计划、按钮存在或构建成功当作功能完整验收。
