# M3 当前功能与使用

2026-10-26，fzk，Codex辅助。人工反馈见[验收记录](acceptance/manual_recheck.md)。

| 功能 | 使用方式与结果 |
|---|---|
| Markdown编辑 | 新建或打开笔记；图标工具栏支持选区格式、列表、表格、代码、查找、大纲、分屏和专注，支持撤销/重做 |
| 阅读模式 | 列表直接阅读或从编辑区切换；标题目录、三档字号、专注阅读与只读资料引用；双链/侧栏继续阅读，切回编辑保留草稿与撤销 |
| 专注笔记导航 | 专注窗口按课程/文件夹/标题筛选，每页30篇；父目录包含子目录，未归档可筛选，切换沿原草稿保护 |
| 笔记AI助手 | 摘要、解释、结构整理、复习问题、自定义；全文或选文预览确认后生成，结果采纳到草稿，可撤销，沿个人保存设置 |
| 多模型 | 原智谱保留；最多8份DeepSeek/兼容Chat Completions配置，AI使用处选择当前模型，共享账户加密与发送确认 |
| 公式 | 点击Σ或Ctrl/Cmd+Shift+M；分类搜索、图形符号、结构字段、嵌套、矩阵/多行与本地预览，保存为标准Markdown公式 |
| 保存与冲突 | 默认手动保存，可用立即保存或Ctrl/Cmd+S；明确开启自动保存后停止输入约2秒保存，阅读期间暂停。本机按账户记住开关；网络失败保留正文，开启自动保存才恢复重试；401/409需处理登录或版本，不静默覆盖 |
| 逐段合并与草稿下载 | 409后按共同版本核对正文/标题/标签/目录；应用保留原副本并等待明确保存，再次冲突仍保护；可分别下载两份完整Markdown |
| 本机恢复 | 主编辑器按账户/课程保留未保存副本，刷新后核对恢复；新副本携带共同版本，旧副本缺基线时不猜测合并；容量/权限失败明确提示 |
| 文件夹 | 最多6级，同课程目录拖动与笔记移动；删除空目录，未归档笔记正常显示和导出 |
| Markdown导入 | 多选UTF-8 .md，文件名作标题，可统一指定目录与标签；逐文件结果、失败重试与请求幂等 |
| 标签与分类 | 标签搜索筛选、批量增删/改名合并、批量移动；推荐归类使用可解释本地规则，经用户确认后移动 |
| 双链/反链与资料引用 | UUID链接保持改名有效；资料引用包含固定版本/定位/摘录，支持回源、去重、刷新和移除；失效来源明确显示 |
| 笔记关系图谱 | 课程内已保存双链的有向图；标题查找、已关联/孤立筛选、一跳聚焦、键盘列表及显式打开；度数按完整当前课程统计 |
| 图片 | 上传并插入或使用图库；每批最多20张PNG/JPEG/WebP，每张10MiB；可编辑名称/说明/标签、查看引用和确认删除 |
| 导出 | 单篇按标题下载.md；选择导出只打包所选笔记与引用图片，保留目录，未归档置根目录，共用图片去重 |
| 标准数据包与课程合并 | 课程／文件夹ZIP自选导出、预览导入；课程可新建或追加到已有课程，所有副本新身份、原内容不覆盖，图片／双链／资料引用重映射；见[验收说明](acceptance/portable_packages_acceptance.md) |
| 回收站 | 中央列表批量删除；回收站恢复、彻底删除、账户清空；默认30天，可设1–365天或关闭，后台定期有界清理 |
| 识别文本 | 在当前笔记中打开文字识别或语音输入，核对后插入光标/替换选区，沿用原笔记保存和撤销，不直接新建笔记 |

导出ZIP需完整解压并保持images相对位置，再用Markdown阅读器打开。单篇.md不携带二进制图片；外链图片不自动抓取。日常ZIP不等于完整账户恢复包。

识别支持图片、PDF、DOCX及配置本地模型后的音频。识别结果需要核对；页号/时间只作来源位置。浏览器实时语音可能使用在线服务；可选本地转写需安装依赖和模型，见[识别说明](acceptance/capture_text_acceptance.md)。

旧识别任务AI整理及其专用API配置入口仍停用；新的[笔记助手和共享多模型](acceptance/note_assistant_acceptance.md)按本轮确认流程使用。普通Markdown导入和M2 AI学习继续使用。M2明确选择/确认个人补充笔记不等同通用的已审阅笔记供M4消费契约，该契约仍待；跨课程/独立完整恢复人工验收继续暂缓。逐段合并用户已复验通过，见[合并说明](acceptance/note_merge_acceptance.md)。[关系图谱](acceptance/note_graph_acceptance.md)只展示本人当前课程有效双链，不推断语义关系或跨课程关系。
