# M3 当前功能与使用

2026-10-19，fzk，Codex辅助。人工反馈见[验收记录](manual_recheck.md)。

| 功能 | 使用方式与结果 |
|---|---|
| Markdown编辑 | 新建或打开笔记；图标工具栏支持选区格式、列表、表格、代码、查找、大纲、分屏和专注，支持撤销/重做 |
| 公式 | 点击Σ或Ctrl/Cmd+Shift+M；分类搜索、图形符号、结构字段、嵌套、矩阵/多行与本地预览，保存为标准Markdown公式 |
| 保存与冲突 | 停止编辑约2秒自动保存，也可立即保存；网络失败保留正文，恢复后重试；401/409需处理登录或版本，不静默覆盖 |
| 文件夹 | 最多6级，同课程目录拖动与笔记移动；删除空目录，未归档笔记正常显示和导出 |
| Markdown导入 | 多选UTF-8 .md，文件名作标题，可统一指定目录与标签；逐文件结果、失败重试与请求幂等 |
| 标签与分类 | 标签搜索筛选、批量增删/改名合并、批量移动；推荐归类使用可解释本地规则，经用户确认后移动 |
| 双链/反链与资料引用 | UUID链接保持改名有效；资料引用包含固定版本/定位/摘录，支持回源、去重、刷新和移除；失效来源明确显示 |
| 图片 | 上传并插入或使用图库；每批最多20张PNG/JPEG/WebP，每张10MiB；可编辑名称/说明/标签、查看引用和确认删除 |
| 导出 | 单篇按标题下载.md；选择导出只打包所选笔记与引用图片，保留目录，未归档置根目录，共用图片去重 |
| 回收站 | 中央列表批量删除；回收站恢复、彻底删除、账户清空；默认30天，可设1–365天或关闭，后台定期有界清理 |
| 识别文本 | 在当前笔记中打开文字识别或语音输入，核对后插入光标/替换选区，沿用原笔记保存和撤销，不直接新建笔记 |

导出ZIP需完整解压并保持images相对位置，再用Markdown阅读器打开。单篇.md不携带二进制图片；外链图片不自动抓取。日常ZIP不等于完整账户恢复包。

识别支持图片、PDF、DOCX及配置本地模型后的音频。识别结果需要核对；页号/时间只作来源位置。浏览器实时语音可能使用在线服务；可选本地转写需安装依赖和模型，见[识别说明](capture_text_acceptance.md)。
