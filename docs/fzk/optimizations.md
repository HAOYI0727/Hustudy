# M3 优化说明

专注阅读将跨笔记导航与本篇标题目录分开，目录按元数据筛选分页、正文按需载入，切换保持草稿保护。新模型接入复用原账户加密和Provider，仅在共享入口切换配置；其他成员页面保留业务布局。笔记助手以完整发送预览和可撤销草稿采纳避免意外覆盖，异步响应按会话/配置作废。[本轮边界、测试与课程包](note_assistant_acceptance.md)。

标准数据包新增独立版本化协议和0022控制记录：原普通阅读ZIP保持简洁，标准包保存迁移关系，账户备份保持空账户恢复规则。预览先列明依赖，再绑定内容摘要确认；所有导入对象新UUID，课程合并追加副本而不猜测同名相同。按需分页窗口、账户隔离请求恢复和旧预览管理减少误操作，未来验收通过脚本自动生成工程外自制样例。[实现与验证](portable_packages_acceptance.md)。

2026-10-27，fzk（Codex辅助）。当前使用见[功能说明](features.md)，实际验收见[验收表](manual_recheck.md)。

| 优化 | 目的与边界 |
|---|---|
| 管理/编辑视图与弹窗 | 侧栏只保留目录和标题；列表勾选靠近批量操作；工具按需打开，关闭不丢当前编辑内容 |
| 独立阅读 | 标题目录、字号和专注视图，保留公式图片/双链/只读回源；阅读显示当前草稿并暂停自动保存，返回编辑保留撤销。加载新笔记时暂禁输入，共享401后晚到保存不恢复自动提交 |
| 目录拖动与批量操作 | 统一检查归属、循环、深度和revision；整批失败不部分修改，保留按钮操作供触屏/键盘使用 |
| 标题命名的简洁ZIP | 只导出所选笔记及必需图片，处理同名和Windows路径规则；先分配路径再重写相对链接，共用图片去重 |
| 共用图片上传队列 | 编辑器与图库共用顺序上传逻辑；成功项保留，失败明确，网络/认证/限流异常停止队列，不自动重放 |
| 保存方式与恢复 | 默认手动，可选自动保存并在本机按账户记忆；开启才前台计时/网络恢复，后台与阅读暂停新保存，关闭取消待发计时；首次创建请求幂等，401/409保留草稿并要求明确处理 |
| 有界逐段合并 | 精确行终止符、共同版本与LCS预算，正文/元数据分别核对；应用前保留草稿，缺基线/超限不猜测，保留完整下载 |
| 只读笔记关系图谱 | SQL元数据投影、去重有向边与同快照计数，最多200节点/400边；默认120节点，筛选和聚焦缩小范围，键盘列表补充图形操作；不读取正文、不调用模型 |
| 可恢复删除 | 软删除时间与保留策略统一；清空核对整个回收站快照；worker锁内重验期限，每轮最多200篇 |
| 本地公式辅助 | 分类/结构/源码共用单一草稿；未知语法原样保留，KaTeX受限渲染，不执行外部宏或网络资源 |
| 识别文本插入 | 保护打开窗口时的笔记会话与选区，核对后才插入；复用编辑器撤销/保存，关闭不写正文 |

当前基于已整合M1/M2/M3/M4的main aa45665。逐段合并为纯前端改动且用户已复验；本轮图谱增加只读API，无迁移或新依赖。[图谱说明](note_graph_acceptance.md)与[合并说明](note_merge_acceptance.md)分别记录本轮与上一轮证据；历史提交验证见[完成审计](m3_completion_audit.md)，实机与人工验收分别记录。
