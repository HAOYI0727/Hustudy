# M3 优化说明

2026-10-19，fzk（Codex辅助）。当前使用见[功能说明](features.md)，实际验收见[验收表](manual_recheck.md)。

| 优化 | 目的与边界 |
|---|---|
| 管理/编辑视图与弹窗 | 侧栏只保留目录和标题；列表勾选靠近批量操作；工具按需打开，关闭不丢当前编辑内容 |
| 目录拖动与批量操作 | 统一检查归属、循环、深度和revision；整批失败不部分修改，保留按钮操作供触屏/键盘使用 |
| 标题命名的简洁ZIP | 只导出所选笔记及必需图片，处理同名和Windows路径规则；先分配路径再重写相对链接，共用图片去重 |
| 共用图片上传队列 | 编辑器与图库共用顺序上传逻辑；成功项保留，失败明确，网络/认证/限流异常停止队列，不自动重放 |
| 自动保存恢复 | 前台计时、后台暂停新保存；网络恢复可重试，首次创建请求幂等；401/409保留草稿并要求明确处理 |
| 可恢复删除 | 软删除时间与保留策略统一；清空核对整个回收站快照；worker锁内重验期限，每轮最多200篇 |
| 本地公式辅助 | 分类/结构/源码共用单一草稿；未知语法原样保留，KaTeX受限渲染，不执行外部宏或网络资源 |
| 识别文本插入 | 保护打开窗口时的笔记会话与选区，核对后才插入；复用编辑器撤销/保存，关闭不写正文 |

数据库迁移、worker与备份适配须由团队整合。没有性能基准或实机证据的部分不声明量化提升；具体自动测试与限制见[完成审计](m3_completion_audit.md)。
