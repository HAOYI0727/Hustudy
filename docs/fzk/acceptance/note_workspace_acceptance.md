## 使用方式

- 左侧是目录和标题导航，不显示正文、标签堆叠或勾选框；窄屏可折叠目录。主区“笔记管理”提供搜索/标签过滤、勾选、全选、清空、批量整理和导出已选，选择和动作在同一区域。
- “编辑笔记/编辑草稿”切回正文；视图切换保持草稿和撤销历史，只有打开另一篇才重置历史。当前草稿未保存/有冲突时，批量整理和拖动禁用。
- 导入Markdown、导出、全部标签管理、推荐归类均从顶部按需打开；笔记元数据、已有图片/双链、图片管理、引用与关联、学习模板按需弹窗。正文保留常用上传图片、格式、分屏、大纲、查找与专注工具。
- 弹窗使用原生模态对话框，背景不可交互，Tab限定在窗口内；Escape或关闭按钮返回触发位置。导入处理中不能关闭，关闭后重开保留文件列表、设置及请求UUID；401先让出原账户登录窗口，恢复后显式重试。导出任务进入后台后可关闭，稍后打开下载。
- 桌面拖动单篇笔记到文件夹；选中多篇后拖动其中一篇一起移动（最多200篇）。拖到“未归档”移出目录。拖动文件夹到另一个文件夹调整父目录；拖动时“未归档”入口变为“移到根目录”，可把子文件夹提升到根目录。
- 文件夹不得移入自身/后代；超过6级、重名、revision冲突由原服务端拒绝。失败显示提示且不假更新归属；刷新列表/文件夹后重试。取消拖动或外部文件拖入不会移动笔记。文件夹仍按名称排序，拖动用于改变归属，不新增同层自定义排序。
- 触屏/键盘无需拖动：通过“编辑文件夹”的上级选择，或主列表“批量整理”的移动目标完成相同操作。

## 建议本人复验

1. 打开笔记页：左侧只显示目录/笔记标题，主区可搜索并勾选两篇；“批量整理”“导出已选”在勾选列表上方。导出窗口应自动选中这两篇。
2. 拖动两篇已选笔记进入子文件夹，再将一篇拖回未归档；刷新页面后位置保留。拖动子文件夹进入另一目录、再移回根目录；文件夹不能拖入自身后代。
3. 在编辑区清空标题后输入一些临时正文，切换到笔记管理再切回，正文应保留、撤销仍有效；管理区禁止拖动/批量操作。测试后恢复标题并保存。
4. 打开“导入Markdown”，选择两份文件但先不导入，关闭再打开，列表与统一标签应保留。再完成导入，重复打开不能自动重新上传。
5. 逐个打开标签管理、图片管理、引用与关联；按Escape关闭并回到触发按钮。小窗口不挤占正文，窄屏内容不横向溢出。
