# 笔记阅读模式与可选保存

2026-10-27，M3-NOTE-READING-04，Codex辅助fzk。分支 `codex/fzk-m3-safe-merge`；用户已明确验收通过。后续新增的跨笔记专注导航单独见[本轮说明](note_assistant_acceptance.md)，不自动沿用此结论。

## 使用

- 笔记管理列表点“阅读”，或编辑区上方点“阅读模式”。标题仍可直接打开编辑。
- 独立正文支持既有Markdown、GFM表格/任务列表、代码、公式、授权图片；可选择16/18/21px字号。
- 目录来自实际渲染的h1–h6，包含下划线式标题，同名标题分别定位，代码块中的#不计入。目录最多展示200项，正文完整。
- “专注阅读”使用原生对话框，Esc退出并返回按钮焦点；资料引用默认折叠，展开后按需读取，只提供回源/刷新，不提供移除。
- 双链和侧栏打开后继续阅读，当前草稿未保存时沿原确认保护；返回编辑保留草稿和撤销历史。
- 自动保存默认关闭，点击“立即保存”或Ctrl/Cmd+S保存。勾选“自动保存”后停止输入约2秒保存，阅读期间暂停。关闭取消待发计时，已发送请求继续按实际结果处理。
- 开关只在本浏览器按已确认账户UUID保存，不跨设备同步，不存正文/凭据；存储失败本次选择仍有效并提示重新核对。本机草稿恢复副本不等于已保存到服务端。

## 边界

无新增依赖/API/迁移或真实模型调用。复用NotePreview的HTML禁用、安全链接、授权图片、本地KaTeX；不下载外链图片。阅读显示当前草稿，未保存/版本冲突明确提示。仅在明确启用自动保存时执行原网络恢复重试，401/409仍需登录或核对。普通编辑预览、分屏和来源管理继续可用。

切换笔记加载期间暂时禁用编辑，避免返回的内容覆盖刚输入的标题；保存请求期间仍可继续输入。共享401立即暂停当前会话，即使此前保存响应晚到，也不能重新开启自动保存或联网重试；已经发送的保存按实际结果确认，后续草稿保留。

## 人工复验与样例

工程旁 `Hustudy验收样例/笔记阅读模式-20261027` 已提供两篇Markdown、PNG与使用说明。

1. 批量导入两篇.md，列表点“阅读”，核对正文/表格/代码/任务列表/公式排版。
2. 点击目录，确认代码中的伪标题未出现，两个重复标题分别定位；改字号，进入专注后按Esc退出。
3. 编辑时上传样例PNG并插入、建立到第二篇的双链；明确保存，再阅读核对图片和连续跳转。
4. 为笔记添加真实资料引用，阅读展开来源，确认可回原文且无“移除此引用”。
5. 默认手动模式输入后等待，确认仍未保存；点立即保存或Ctrl/Cmd+S核对结果。开启自动保存后再修改，确认正常定时保存；关闭后不再定时提交。
6. 开启自动保存后修改，立刻进入阅读，确认未保存草稿可读且不提交；返回编辑检查撤销/重做。窄屏核对正文无整页横向溢出，宽代码与表格可局部滚动。
