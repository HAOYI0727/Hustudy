# 设计决策记录

## ADR-0001：本地优先单体

采用 FastAPI + SQLite + 本地文件存储的单体结构，符合 `main_idea.md` 和协作指南，先降低四人集成成本。耗时解析与模型任务后续放入数据库任务记录和独立 worker。

## ADR-0002：根目录作为唯一工程根

现有课程提交材料在 `hustudy/` 子目录，新增代码统一位于根目录。根 `Hustudy_requirements.md` 只作为入口，避免需求正文出现两份漂移版本。

## ADR-0003：Phase 0 暂用开发期建表

应用启动暂用 `Base.metadata.create_all` 让骨架快速可运行；正式接入成员模块前必须生成第一版 Alembic revision，并移除自动建表，迁移由 A 统一维护。

## ADR-0004：当前环境与目标运行时分离

项目依赖目标为 Python 3.12；当前工作环境为 Python 3.9.6。Phase 0 类型写法保持 3.9 语法兼容，但未宣称依赖已在 3.9 安装或运行通过。

## ADR-0005：四人记录隔离与公共契约统一（2026-10-13）

依据用户本轮要求，collaboration 与 docs 各设 zhy/xtc/fzk/gcx 四人成员目录，分别维护个人进度与功能/优化证据。公共根级文件维护唯一的规则、操作、API、契约和集成事实；既有跨模块历史不重分配贡献。collaboration/handoff.md 持续追加独立条目，接收由成员本人复验，队长汇总到任务板/进度/追踪。规范见 AGENTS 第 20 节，成员映射见 collaboration/roles.md。本决策不改变产品 schema、数据库或四模块代码边界。

## ADR-0006：统一工作台视觉与可追溯资料整理（2026-10-13）

依据用户要求，所有模块沿用同一背景、卡片、按钮、焦点、图标笔画与交互反馈；模块配色仅用于标题和少量强调。公共手绘 SVG 在 Icon.tsx 维护，不引入图标依赖或外部字体请求；PageTitle、ModuleStats、空状态和返回顶部复用。装饰动效较轻，遵循 prefers-reduced-motion；窄屏使用同一控件系统，保留键盘标签和禁用态。

资料分类/标签属于 Document 展示元数据，版本内容保持不可变；服务端精确标签过滤，最新版本范围不回退旧内容。原文→笔记采用 M3 只读服务接口，按有效版本与归属校验，不由 M1 直接查询笔记表。资料整理显式保存，轮询只刷新列表和任务，保留编辑草稿；离开未保存整理时提示。决定不代表全部 FR-09 或真实易用性试用已验收。

## ADR-0007：当前完成判断与历史证据分开维护（2026-10-15）

用户要求核查队长完成情况并正确分类文档。collaboration/zhy/task_status管理正式A01–A10的当前任务，docs/zhy/completion_audit列技术证据；个人技术报告按shared_platform/materialhub/integration/history分类，公共契约/API/操作/集成结论仍在根级。原功能日志保留在history，features维护当前功能分类。早期任务板是聚合编号，不能代替正式十任务；归档只调整链接，不改历史结果或代记人类成员接收。

本轮没有批准技术偏差：现有两段签名令牌不是标准JWT；前端useState导航/手工请求尚未采用规划路由、请求管理和组件库，Python当前实测3.11.15与目标3.12有差异。应补实现或提交正式基线变更评审，不把“已经运行”写成选型全部符合。此前ADR-0003/0004仅为早期记录，当前已采用Alembic，环境及剩余项以[核查](zhy/completion_audit.md)为准。

## ADR-0008：实现既定前端基线与保留草稿的重登（2026-10-15）

PLATFORM-WEB-BASE-01沿用既定React Router/TanStack Query/Ant Design，补齐ADR-0007记录的实现偏差。共享布局CSS与手绘SVG保持统一，组件库用于主题/告警/重登；模块按需加载。页面状态由URL驱动，路由统一接入现有离开保护。GET按会话和写入代次去重，后续读取每次重新授权；无令牌query key和持久缓存，变更不重试。

会话失效保留原工作区并要求同账户登录，不再直接卸载笔记草稿。重登不重新初始化初始笔记/资料整理状态，失败写入需显式重试，不重发模型请求。Python3.12独立锁依赖回归通过，未切换现有运行解释器。最新证据与剩余边界见[共享前端验收](zhy/shared_platform/web_base_acceptance.md)，不以本切片替代正式人类评审/发布。


## ADR-0009：统一密度、按可用宽度重排与触控抽屉（2026-10-15）

PLATFORM-RESPONSIVE-01响应用户全站多屏优化要求。共享responsive.css维护字体、卡片间距及断点；桌面侧栏208px（中等桌面188px），1100px以下用原生dialog抽屉以保留工作区宽度。依浏览器焦点行为补首尾Tab循环，Escape/遮罩关闭并恢复触发按钮；以路由真正变化关闭菜单，不绕过未保存保护。导航顺序按课程→阅读→笔记→AI→试卷→复习→查找→备份排列。

760px以下资料/笔记目录折叠但内容持续挂载，避免草稿/文件状态丢失；阅读与编辑仍在同一页面。各模块仅展示容器/样式接入，不改业务算法/API/schema。界面13px基础字号、20–26px标题，文档/阅读字号独立；触控44px热区、16px表单。长课程描述最多显示3行，完整内容可通过整理查看；代码/表格只在自身容器滚动，不裁剪整个页面。实机与真人反馈另列，不将浏览器模拟写成人工试用完成。


## ADR-0010：用公共色板与真实状态统一前端细节（2026-10-16）

PLATFORM-VISUAL-02保留既有密度和断点，统一主色/文本/边框/焦点及成功/警告/失败语义；模块色仅作轻量标题强调，不能靠颜色独自表达状态。关键辅助文字提升可读性，不继续整体缩小。字体使用系统栈，无远程字体/装饰图依赖，Ant Design主题同步主色。

顶部突出当前工作区，账户放入侧栏，长名称省略；按功能区分空状态图形、补齐按钮图标与可见表单标签。所有交互继续使用既有路由、未保存保护和发送确认，减少动效偏好下取消位移。关键配色在浏览器实际DOM抽样测对比度，但不宣称全站无障碍认证或用户满意度。范围无API/迁移，证据见[本轮验收](zhy/shared_platform/visual_polish_acceptance.md)。

## 2026-10-16 M2报告复用任务与数据结构

M2-STUDY-REPORT-01沿用RemoteQuery/AIResult/AI_ANALYSIS，不新增数据库字段/迁移。不可变的报告任务参数以版本化保留前缀+严格JSON信封存在query字段；普通问答拒绝该前缀，HTTP响应只展示学习目标并单列report_scope。派发时由服务端解码选择固定报告Prompt/schema，用户资料始终为数据。备份原样保存并验证恢复不重新派发。未来若新增更多任务种类，可由队长评审专用元数据列迁移；当前不让M2私自改共享schema。

报告独立于问答关键词检索，使用有界顺序来源及覆盖说明；有证据不等于学科结论正确。接口传输依据[智谱官方API](https://docs.bigmodel.cn/cn/api/introduction)于本日核对通用端点、Bearer和chat/completions；本轮不改模型选择或宣称政策已核实，不调用真实服务。
