# 设计决策记录

## ADR-0001：本地优先单体

采用 FastAPI + SQLite + 本地文件存储的单体结构，符合 `main_idea.md` 和协作指南，先降低四人集成成本。耗时解析与模型任务后续放入数据库任务记录和独立 worker。

## ADR-0002：根目录作为唯一工程根

现有课程提交材料在 `hustudy/` 子目录，新增代码统一位于根目录。根 `Hustudy_requirements.md` 只作为入口，避免需求正文出现两份漂移版本。

## ADR-0003：Phase 0 暂用开发期建表

应用启动暂用 `Base.metadata.create_all` 让骨架快速可运行；正式接入成员模块前必须生成第一版 Alembic revision，并移除自动建表，迁移由 A 统一维护。

## ADR-0004：当前环境与目标运行时分离

项目依赖目标为 Python 3.12；当前工作环境为 Python 3.9.6。Phase 0 类型写法保持 3.9 语法兼容，但未宣称依赖已在 3.9 安装或运行通过。
