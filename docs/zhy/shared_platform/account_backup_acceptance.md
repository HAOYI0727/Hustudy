## 已实现

“备份与恢复”独立页面无需先选课程。后台生成完整账户ZIP：课程、四格式原件/不可变版本/Chunk、可读图片、人工来源、终态任务、笔记/双链/Citation、AI结果/保存的发送记录、真题/蓝图/试卷/作答/错题/复习/反馈。保留UUID/UTC/原文定位/文件hash及当前账户时区。用户密码/凭据、.env/密钥不导出；检测到业务文本包含当前服务密钥时拒绝。课程资料ZIP是可重建缓存，保留记录但不重复导出其压缩文件，恢复后显示不可下载，需要重新生成。

删除/撤权资料只保留失效身份/引用元数据，不导出原件或正文；旧服务端备份下载重新核对版本/图片/人工来源有效性。已下载本地副本不能撤销。恢复不重新运行模型，原发送任务必须为终态；FTS按恢复后的原Chunk重建。

恢复只允许当前登录账户没有任何业务对象，原账户身份不迁入，新账户密码/UUID不变；所导入业务对象UUID保持。相同UUID已在同库存在则拒绝，因此不能在保留源对象的同库新账户中复制，需要迁往新数据库的空账户。界面明确说明并要求输入“恢复到空账户”。校验文件后在同一事务插入，失败回滚并清理本次新文件；不覆盖既有对象。

ZIP路径/符号链接/重复和额外成员、schema/table/字段/归属/UUID/时间/JSON/FK、文件大小/hash及Citation版本/定位/摘录hash均校验。限压缩256MiB、内容512MiB、元数据16MiB、70000成员/100000业务行/120秒；租约180秒，过期任务标FAILED，不自动重放恢复。最多50条记录，终态记录可移除，移除不删除已恢复学习数据；运行中不能移除。不是ZIP真实性签名或AI语义正确性证明。
