## 可以直接使用的功能

1. 左侧「知识点学习」或课程首页「知识点学习中心」进入。按名称/别名搜索，筛选有待复习错题、尚无确认题目的知识点，12项一页，URL保留选定知识点。失败可重试；合并后的旧链接明确选择目标，不静默替换。
2. 详情按“原文→自己的理解→练习与复盘”呈现。人工确认依据固定原文版本；本地关键词候选折叠展示，对照后显式确认，沿用原Topic revision。来源撤回显示不可用，不提供原文或改成新版本。
3. 笔记区列出引用同一有效片段的笔记、同名标签候选，分别标注；只读取元数据，点击才打开正文。名称命中不是人工关联，普通笔记不会自动成为AI输入。
4. 「按此知识点设置练习」只预填标签，默认从1题开始，仍由用户选择题数/题型/时长并显式抽取。已有进行中作答保留；无效/错配/合并标签不回退到全课程抽题。题数显示为记录数，可抽资格仍由原服务端校验。
5. 当前未标掌握错题来自原重做/再出错规则，包含子标签；最多展示最近6条，可直接复盘。关联PENDING复习计划显示账户时区日期，打开原错题安排/改期/完成；本页不自动创建计划或把任务完成当掌握；即使错题已标掌握，仍保留显示关联的未完成计划。
6. 资料库设置关键词、分类、标签、状态及排序后，在「常用视图」保存。可应用、改名、删除或刷新；最多8份，名称唯一且1–32字。本机按账户UUID/课程隔离，应用仅改变筛选与资料页码，已选资料与阅读版本保留。存储失败不影响原筛选。

界面采用统一蓝紫色板、轻量渐变入口、主从两栏和明确的关联标签；去掉重复宣传卡片。窄屏顺序显示，选择后定位详情并可返回列表；键盘焦点有明确去向。图标复用项目自制SVG，不复制竞品品牌或图片。知识点页面独立懒加载，生产构建入口约194.81kB（gzip63.26kB），不把分块大小当真实加载速度测量。

## 边界与接口

- `GET /courses/{id}/learning-topics` 与 `/{topic_id}`均验证有效本人课程；Pydantic白名单不返回题干、答案或笔记正文。目录不读取全部Topic来源摘录，题库只选标签/状态元数据；M1/M3各自只读适配后由共享层编排。
- 每次GET为只读快照，不创建统计快照或写STALE、不推进revision；2000个Topic/20000条题目/20000条错题的元数据预算，超限明确422。分页总数为当前筛选，不承诺跨请求冻结。
- 人工确认原文最多本考点20条，候选最多6条；同源与标签候选笔记各最多6篇。题目/错题统计含子标签，原文/笔记是本考点范围，不把父子计数相加称独立题数。
- 视图只存筛选元数据，单课程32KiB、8份；无token、密钥、正文、服务器同步或账户备份持久承诺。损坏/未知结构/非法筛选拒绝读取，写失败保留已有状态。后续可另议跨设备同步。
- 空错题列表不等于学科已掌握；学习建议不代表考试预测。图谱、语义检索、自动间隔复习、独立闪卡、审阅笔记供AI仍是后续契约，不恢复停用的AI出新题/笔记整理。
