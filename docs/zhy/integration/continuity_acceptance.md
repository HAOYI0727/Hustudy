## 本轮功能

| 入口 | 用户可以做什么 | 实际边界 |
|---|---|---|
| 资料阅读 → 阅读笔记 | 原文旁写理解，显式附加当前版本片段，保存后预览关联笔记或进入完整编辑器 | 宽屏并排、窄屏纵向；复用原子新建与Citation，未确认结果只重试原request_id；不调用模型 |
| 知识笔记 → 本机恢复副本 | 刷新后找回未保存的标题/正文/标签/目录，核对原revision后显式保存 | 当前浏览器、账户/课程隔离；恢复暂停自动保存，删除/无权原笔记只允许复制副本，不自动新建 |
| 笔记目录与管理 | 正文关键词/标签筛选、20项展示分页、跨页勾选与原目录/双链/导出 | 仍读取完整的分页元数据索引以保留整库功能；仅选中编辑/预览时读取正文，不宣称所有索引均只加载一页 |
| AI → 资料问答/学习报告 | 按名称/分类/标签检索资料，每页12份，跨页保留最多20份已选版本 | 保留历史版本；翻页或搜索不会生成预览/请求模型，最终发送仍须原确认流程 |
| 考点、统计与蓝图 → 标签 → 题目 | 每页20道摘要，展开才读取完整题干/选项/插图，详情失败可重试 | 不改变题库记录与父子同题去重；管理详情沿原无活跃作答限制，考生接口不增答案 |

恢复副本不替代备份：最多20份、单份序列化1MiB、账户合计3MiB、30天有效。容量不足/隐私模式禁用存储时明确提示，不静默淘汰未过期副本。每个编辑会话独立记录；恢复来源副本保留，核对保存后可手动删除，避免另一个窗口的内容被清理。阅读侧栏草稿也能在知识笔记恢复，含冻结请求与原文引用。

目录元数据与匹配ID最多20000项；超过限制明确失败。分页期间总数/ID发生不一致会要求刷新；多次请求不具有跨请求冻结快照，不承诺完整捕获等量并发替换或元数据更改。单笔记保存仍由revision作最终检查。

## 本轮修正与复验方法

- 恢复另一份副本前为当前未保存草稿保留独立记录，避免复用记录ID覆盖；已有恢复来源仍保留。
- 笔记目录分页导航名称与标题输入框区分，恢复后不自动提交；409核对后仍需显式保存。
- 阅读引用按Unicode字符截取前500字，表情位于边界时保持完整并通过后端逐字校验。
- QA/报告不再显示停用候选生成的说明；罕见路由告警按需加载，构建无超过500kB块提示。构建分块变化不等于已测首屏速度提升。
- WebKit测试保留真实multipart文件：图片请求直接放行原浏览器正文，模拟MD响应丢失时用原request_id及自制文件完成服务端请求；断言仍核对实际内容与不重复创建。光标定位等待requestAnimationFrame完成后断言，不放宽选区结果。
