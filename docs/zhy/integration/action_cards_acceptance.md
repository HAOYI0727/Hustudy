## 当前功能与设计

首页四张学习阶段卡片在真实计数之外，增加可继续项目的标题、状态、更新时间和直接入口。资料回原版本，笔记回原编辑器，学习结果回已保存问答/报告，练习恢复原作答和已保存答案；各卡保留独立工作区按钮。仅在各域最近摘要中选择可用记录，不将最近更新冒充真实阅读位置或完整历史；真正的上次阅读片段仍使用资料页的「继续上次阅读」。练习卡只显示进行中的作答，交卷后不继续当成待作答。

卡片采用同一主题的图标封面、几何水印、真实记录内框与实色底部动作，保持一致留白、适中字级和状态色。加载、失败和空态给出不同说明；单域失败仍可独立重试，其他卡片可用。所有快捷打开均复用原UUID路由与权限，不新建作答、笔记或模型任务。

资料卡片增加文件折角封面、版本、当前打开标记、分类/大小/标签/日期。解析、索引、预览分别显示真实状态，解析成功不再在列表中掩盖索引处理中或预览失败。原件及兼容预览能力仍由原阅读工具提供，状态失败可打开详情检查；不会因为某一派生任务失败禁止阅读已经可用的原文。

资料库「详细 / 精简」切换仅影响当前页面显示。精简收拢封面、说明与标签，保留标题、版本和三个状态；切换不请求数据、不清除筛选/页码/跨页选择，不重挂阅读器，不改写未保存整理。保留独立勾选框与原整理冲突处理。显示方式不跨页面保存，不增加外观或常用筛选字段。
