## 完成的学习路径

资料阅读 → 摘录为带引用笔记 → 当前版本问答/学习报告 → 审阅后保存笔记并直接打开 → 从本人题库练习 → 保存与继续作答 → 交卷/自评 → 错题回源 → 安排下一次复习。

闭环使用同一账户与课程，保留原DocumentVersion/Chunk/Citation/试卷和作答身份。真实AI继续逐次预览/同意/确认；自动化以固定自制报告和模拟错误验证，不调用真实Provider。题库仍只提供选择题/解答题并本地抽题，M3识别仍仅插入当前笔记，不恢复停用的AI出新题/笔记整理。

## 只读接口与模块边界

新增 `GET /courses/{course_id}/workspace/{domain}`，domain为materials/notes/study/practice。共享入口验证有效课程，开启只读快照，各模块独立适配器只读取本域表；响应counts/recent/checked_at，近期项目最多6项，不读取或返回内容正文/标准答案。已核验题目数是记录数，抽取资格继续由原规则和来源检查决定。

新增 `GET /mistakes/{id}/sources`，沿原作答检查账户/课程，按历史快照校验来源并返回可用/失效，不猜测关联。不再借用带课程写锁的校验路径：共享checked_chunk新增内部lock_course开关，默认保留原变更保护，本只读适配器显式关闭写锁；风险测试捕获SQL确认GET没有INSERT/UPDATE/DELETE/REPLACE。

新增 `GET /review-tasks` 分页查询本人可访问的待办/全部计划，包含账户today/timezone；原创建幂等、完成和expected_due_date改期接口复用。旧 `/review-tasks/today` 继续兼容；已移出错题及已删课程不作为活跃计划展示。`GET /attempts/{id}` 新增可选course_id校验，其他旧调用兼容。

M2增加来源/结果预选与成功笔记直达，保留生成器及严格结构/引用校验；M3只补摘录消费与通用弹窗焦点，不重写编辑/冲突/公式/撤销/回收站；M4只补路由/来源/计划展示及只读适配，不改变抽题、判分、主观自评或旧快照。

## 浏览器核查中修复的问题

- WebKit点击按钮默认不聚焦，原笔记弹窗关闭后无法回到实际触发按钮。通用NotesDialog记录实际指针触发点；键盘打开仍按活动元素恢复，Tab明确在可用控件间循环，Escape/导入处理中关闭边界保留。
- 单选知识标签搜索在WebKit点击候选时，输入框blur先清掉候选，导致点击丢失。候选在pointerdown阻止输入框提前失焦，保留键盘路径与原业务选择规则。
- 新增错题子组件使用了相同兄弟key，已为安排复习组件分配独立key，并在完整闭环中检查重复key控制台错误。
- 旧视觉测试仍查找“进入课程工作台”，已跟随实际“继续阅读资料”文案更新；保留真实颜色对比与减少动效断言。
