## 当前设计

全站采用一个当前主色，默认沿用鸢尾紫；已保存的六预设或自定色继续有效。资料、AI、笔记、题库、复习与查找/备份/API/指南/反馈，以及学习记录、导航和首页卡片使用相同主色。用图标、标题、步骤和布局识别不同功能。

主动作使用实色，卡片浅底与边线使用同色系的不同明度；减淡原先大面积模块底色，保留渐变、柔和阴影、轻微悬浮与清晰边框。首页和分界面采用相同的角色变量，原模块变量名称仅作兼容别名。知识点选中边线/计数/步骤和课程标签也改为随主色联动，清理固定装饰色。

实际截图复核后继续清理首页说明卡、近期活动图标、AI报告知识类别、复习知识标签及题干工具框/拖动提示等遗留装饰色；限定工具标题选择器，保留Markdown题干正文。新增浏览器断言核对说明卡浅底、活动图标同色及成功状态独立，不只检查根变量。

保留Times New Roman及中文黑/宋/楷角色、适中字号、触控尺寸、布局宽度与密度设置。成功、警告、错误、掌握与危险操作保留语义色；阅读正文、代码、公式、图片、Office/PDF原件保持原表现。无全局滤镜、正文重染、API/后端/schema/依赖或新偏好字段，旧浏览器偏好无需迁移。

## 使用

在任意工作区点击右上角「外观」，选择主题色或自定颜色。卡片、导航、按钮与各工作区一同更新；切换不离开当前页面，保留草稿、阅读字号和已选内容。
