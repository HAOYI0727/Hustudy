## 本轮交付

M1的services/ai_context提供有界只读候选与来源验证，M2不直接读取笔记/考试内部数据。关键词BM25选同课程/本人有效最新版本，支持显式版本/片段范围；人工来源只允许当前确认文本。最多6片段，每片段2000字符、总8000字符，问题2000字符。没有证据不调用模型，不使用语义搜索。

RemoteQuery/0011保存不可变问题和来源快照、模型/端点、15分钟预览有效期、确认/派发时间、job/result关系。预览不调用模型；严格布尔确认只提交预览ID，不接受浏览器重写片段。相同预览确认幂等、每课程一个活跃远程任务、最多20条未确认预览。确认与派发重新验证归属/有效性/原文hash。当前密钥若出现在问题或片段中则拒绝预览/发送，不能把它当课程数据上传。

后台AI_ANALYSIS使用原租约写回、单次网络调用、全局串行、180秒租约、45秒读超时/60秒处理预算、响应≤1MiB和输出≤2048tokens。HTTP等待不占SQLite写锁。返回坏JSON/非法结构/假引用/未完整输出/鉴权/限流/超时均provider_error，不回显供应商错误体或思考内容。grounded引用只取实际发送片段的真实连续原文，验证位置不代表解释语义正确，结果标UNREVIEWED。没有自动结构修复或网络重试；失败需重新预览确认。

取消/删除在派发前阻止模型调用；已派发请求无法召回，但租约/来源条件阻止迟到结果保存。课程删除通过M2生命周期服务取消任务并清理RemoteQuery/结果；资料删除/人工撤回取消对应任务。已有结果不因新失败覆盖，读取时重新计算引用可用状态。

前端保留本地演示检索，新增真实模式、资料范围、完整发送预览、政策未核实说明、逐次确认、轮询/取消/恢复本次请求、真实结果标识、Markdown安全显示、原文回源和可编辑笔记草稿。草稿引用冻结为创建草稿时的来源，解决新问题覆盖旧草稿引用的问题。真实章节报告和M4生成不自动切为真实模型，旧real模式接口明确提示使用新问答流程。
