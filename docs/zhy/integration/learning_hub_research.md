# 官方产品研究与本轮迁移（2026-10-22）

Codex辅助zhy。用户授权查阅同类网站功能及设计；以下来自官方帮助资料，属于交互思想借鉴，不引入其源码、图片、品牌或付费资源。

| 官方参考 | 核实的交互思想 | Hustudy本轮迁移 |
|---|---|---|
| [RemNote References](https://help.remnote.com/en/articles/6030714-references) | 将概念、想法与笔记段落用引用连接，支持概念间导航与别名 | 用现有Topic/版本片段/Citation聚合学习入口，不另建一套身份/知识库 |
| [Obsidian Backlinks](https://help.obsidian.md/plugins/backlinks) | 明确链接与未链接提及分别呈现，可在上下文查看关联 | 已确认原文、引用同源片段的笔记、同名标签候选分别标明；关键词命中不称已确认 |
| [Readwise Reader组织方式](https://docs.readwise.io/reader/docs/organizing-content)、[默认视图](https://docs.readwise.io/reader/guides/filtering/default-views) | 用标签/筛选视图组织同一资料库，常用视图可固定，继续阅读为独立入口 | M1保存当前筛选并一键应用；保留既有版本阅读位置，不复制其复杂查询语言 |
| [Notion视图](https://www.notion.com/help/views-filters-and-sorts)、[布局](https://www.notion.com/help/layouts) | 同一数据可按视图浏览；主内容和详情分区，常用属性前置，次要属性按需展开 | 学习中心采用可搜索列表与详情、分组卡片和清晰下一步，手机顺序浏览，保持键盘/44px触控 |
| [Quizlet练习设置](https://help.quizlet.com/hc/en-us/articles/25946589648013-Studying-with-Practice-Tests) | 学习材料进入练习前明确题数/题型/时长，提交后回顾 | 仅借鉴练习前设置与事后复盘；沿用本人已确认题库本地抽题，不恢复AI出新题或新增题型 |

迁移判断：优先解决“同一个知识点的课件、理解与错题分散在不同模块”以及“每次重复设置资料筛选”的真实摩擦。主题统计只描述当前记录，不展示虚构掌握率，不把笔记当已审阅AI来源。自动间隔复习、图谱、独立闪卡和语义检索保留后续评审，不把产品宣传当已验证教学效果。

实现契约见[LEARNING-HUB-04](../../contracts.md#learning-hub-04)，实际功能和验证将在本轮验收中记录。链接核查日期为2026-10-22，产品后续可能变化。
