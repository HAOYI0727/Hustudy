## 本轮新增与优化

1. **按所选资料导出**：资料库进入「批量整理分类与标签」，跨页勾选后「导出已选」，自动展开资料包并列出范围。生成时固定提交所选资料当时的全部版本，只附带这些版本的来源图片；不加入未选课件、后来新增版本或无来源图库图片。原「整门课程」导出仍可使用。
2. **重复提交与异常保护**：同一请求只能对应同一选择集合。网络/服务错误或登录过期后保留原请求与选择，明确点击「核对并重试原请求」；即使改变当前勾选也不扩大原请求。已有任务返回同一记录，失败任务重试保留尝试次数及原版本范围。专注阅读隐藏导出区但保留其状态；主动确认离开页面后需从导出记录核对任务，不保证浏览器崩溃后恢复未确认请求身份。
3. **任务更容易定位**：处理记录支持解析/索引/预览类型与状态组合筛选、分页，切换任务条件不刷新资料目录；旧筛选的迟到响应不覆盖新列表。每条记录可「回到资料版本」，包括旧版本和当前资料页之外的课件，仍经过未保存整理/阅读笔记保护。

## 按职责全面核验

| 方面 | 建议体验 | 正常结果与异常边界 |
| --- | --- | --- |
| 认证/会话/权限 | 两个测试账户分别建课；打开另一账户的对象链接；编辑中模拟登录过期 | 越权对象404；401先重登原账户，草稿保留，不自动重放保存/导出/模型发送；不靠前端隐藏实现权限 |
| 课程组织 | 改名/分类/标签，两个标签页同时修改，再尝试删除测试课程 | revision冲突明确核对，不能静默覆盖；删除有名称确认和关联数量提示，相关文件/检索撤权 |

| 阅读与笔记 | 阅读侧边笔记、摘录引用、未保存离开、书签改名/搜索、浏览器刷新 | 引用保留版本/片段UUID；拒绝离开保留编辑；书签与阅读位置仅当前浏览器，不能当跨设备同步 |
| 任务/恢复 | 类型与状态筛选、分页、取消、恢复、回历史版本 | 解析/索引/预览分开，取消撤销租约，不写迟到结果；仅失败/取消且未达上限可恢复。已达上限不能靠新请求重置预算 |
| 资料包 | 整门课程与所选范围分别导出；选择后上传新版；失败后重试 | 选择包范围固定，清单/文件hash一致；重试不加入新版本；删未选资料不影响选择包，删包内来源/撤回文字后禁止旧包下载 |

| 外观与可访问操作 | 外观切换主色/页面基调/密度/宽度；键盘、390px手机和桌面 | 全站同一主色、状态语义独立；原文/公式/Office不重染；卡片/按钮对齐且触控44px，切换不丢当前编辑 |

### 共享基础层：账户、课程和导航

- [ ] **S01 注册与正常登录**

  操作：在独立测试浏览器注册验收账户A；退出后用相同凭据登录，再用错误密码尝试一次。

  通过：正确凭据可登录，错误凭据有提示且不能进入账户；不要用日常账户反复试错。

- [ ] **S02 刷新和退出**

  操作：登录A后刷新页面；再明确退出并尝试打开刚才的资料地址。

  通过：刷新保持有效会话；退出后需要登录，地址本身不能绕过认证。

- [ ] **S03 创建课程**

  操作：课程总览→新增课程空间，建立「队长验收主课」与「隔离与撤权课」，填写描述、分类和标签。

  通过：刷新后两门课程仍存在，名称/描述/分类/标签与输入一致。

- [ ] **S04 课程整理与筛选**

  操作：整理主课并改名/描述/分类/标签；用搜索、分类、标签和排序查找，再重置筛选。

  通过：各条件生效，重置恢复列表；课程标签不自动改写资料或笔记标签。

- [ ] **S05 课程隔离与空态**

  操作：在主课导入资料后切到尚无资料的隔离课，分别打开资料、笔记、知识点和记录。

  通过：不混入主课数据；空页面说明如何开始，不是白屏或加载失败。

- [ ] **S06 课程并发冲突**

  操作：两个标签页同时打开同一测试课程的整理表单；第一页保存后，第二页保存不同改动。

  通过：第二页明确提示冲突，保留本地输入，可核对服务器内容后再决定；不能静默覆盖。

- [ ] **S07 地址、刷新和前后退**

  操作：从资料片段打开笔记再回源；复制地址到同账户新标签页，刷新，并操作浏览器后退/前进。

  通过：回到对应课程/原UUID/版本或片段；地址没有密码或token；未保存离开仍受保护。

- [ ] **S08 跨账户读取**（需账户B；仅测试自己的验收对象。）

  操作：在另一浏览器或独立配置中登录账户B；打开A的资料/笔记/版本地址，并尝试其已复制的文件下载地址。

  通过：B不能看到A的内容，服务端拒绝读取；不要把两个普通标签页当成独立登录环境。

### 资料导入、校验与不可变版本

- [ ] **U01 四格式单次导入**

  操作：资料阅读→导入新资料，分别上传fixtures中的MD、PPTX、DOCX和PDF。

  通过：每份都有保存/处理反馈；原件入库不等于解析、索引和预览均成功。

- [ ] **U02 多选与拖放**

  操作：同时选多份小文件上传，再用拖放添加另一批不同内容的小文件。

  通过：队列逐项显示进度与结果，完成项保留；一次添加新版本只允许一份。

- [ ] **U03 重复内容**

  操作：把已上传的同一文件再传一次，记录导入前后资料数与版本数。

  通过：按现有去重规则返回已有对象或明确重复反馈，不无提示地产生重复版本。

- [ ] **U04 格式与大小拒绝**

  操作：选择一个不支持的扩展名；有合适样例时再选大于30MiB的文件或超过20份的一批文件。

  通过：明确拒绝或要求缩减；未提交的无效文件不显示为成功，不需要故意占满磁盘。

- [ ] **U05 上传部分成功与暂停**（需浏览器请求故障模拟；无法触发时记条件未具备。）

  操作：用测试队列先成功上传一份；在后续文件请求时模拟网络失败，恢复连接后核对资料库，再明确重试未成功项。

  通过：先前成功项保留；网络/服务/认证异常暂停后续，恢复网络不自动重放整批。

- [ ] **U06 同资料新版本**

  操作：选中MD→为选中资料添加新版本，上传改过正文的UTF-8文件，记下v1/v2和独有词。

  通过：同一资料下出现新版本，v1仍可读；不是覆盖旧原件或把旧引用改到v2。

- [ ] **U07 新旧版本定位**

  操作：在v1建引用或书签，切到v2阅读后从该引用/书签返回。

  通过：仍回v1和原片段，新增版本没有破坏旧来源身份。

### 阅读排版与四格式预览

- [ ] **R01 长PPT初次打开**

  操作：在主课选择一份已有长PPT；没有资料时导入自己的测试副本。

  通过：无明确片段定位时默认单页原格式，加载后定位阅读面板，不把几十/上百页全文展开。

- [ ] **R02 PPT页码与演示**

  操作：使用上一/下一幻灯片、页码输入、缩放和演示模式；跳到末页，再按Escape退出演示。

  通过：页码和画面一致，可到完整原件末页，退出恢复正常布局；包含隐藏页。

- [ ] **R03 PPT文本分页**

  操作：点击文本与引用，选择靠后页码和最后一页，再前后翻页。

  通过：每次一个文本片段，显示范围/总数；正文完整，末页不是空白或仍显示第一页。

- [ ] **R04 长MD/DOCX文本**

  操作：打开有较多段落/标题的资料，用目录跳到末段，滚动正文区。

  通过：每组最多6片段，正文区高度有界且可读完整文字；目录先切到对应组再定位。

- [ ] **R05 整版本查找**

  操作：在末几页选择一个独有词，在当前版本原文中查找；清空关键词再翻页。

  通过：即使该词不在当前文本页也能命中；清空恢复完整范围，不把搜索局限于已展开DOM。

- [ ] **R06 PDF与Word**

  操作：PDF预览翻页/缩放；Word预览核对粗体、表格、图片与前后阅读页。

  通过：内容可读且不溢出；Word阅读页不是原Word页码或正文块编号；复杂版式差异如实记录。

- [ ] **R07 兼容预览与降级**

  操作：在PPT/Word原格式和兼容预览（PDF）之间切换；原格式失败时点显式重试或返回文本。

  通过：两种路径独立，兼容PDF失败不假称原格式也失败；没有转换器时有说明，正文仍可读。

- [ ] **R08 原件、字号与专注**

  操作：下载原件用本机软件核对；调整阅读字号，进入/退出专注；需要图片时展开课程图片与截图。

  通过：原件名称/内容正确；字号只调阅读，原页/公式不被重染；专注与折叠不丢输入，工具仍可找回。


- [ ] **R09 打开AI阅读助手但不自动发送**

  操作：选择有正文的PPT，点击阅读工具栏AI阅读助手；核对当前预选版本。

  通过：原PPT仍可读；打开工具/切总结侧重点不自动调用模型。真实生成须本人核对预览并确认。

- [ ] **R10 生成并查看知识点总结**

  操作：在当前课件专用助手选择全面梳理/复习提纲/笔记写作，核对可编辑提示词、固定版本及文字覆盖，再由本人同意发送；无模型可用materialhub_demo.md固定演示。

  通过：知识点/建议/例题与引用在知识点与结果区显示；失败或部分结果有说明，演示不冒充真实PPT讲解。

- [ ] **R11 结果引用与版本历史**

  操作：点击依据回当前原文，检查版本、片段和助手状态；查看已保存结果。

  通过：同版本回源不卸载助手/草稿；历史只匹配可确认单独属于当前版本的报告，排除混入其他课件；课程最近20条不是完整版本历史。

- [ ] **R12 总结整理为自己的笔记**

  操作：点击整理为可编辑笔记草稿→审阅标签/理由→编辑正文补充理解→明确保存。

  通过：引用随笔记保存且可回原文，AI建议与用户整理区分；不自动保存或标已核实，单篇最多50引用。

- [ ] **R13 侧栏切换与离开保护**

  操作：写阅读笔记，再切AI助手、收起/重开，检查原输入；写AI草稿后切其他资料并取消离开。

  通过：两个侧栏轮流显示、已有DOM和草稿保持；跨版本/课程需处理未保存内容，正文不被新结果覆盖。

- [ ] **R14 离线和保存未知**

  操作：在测试账户首次离线打开助手，恢复后明确重试；需开发协作时模拟笔记保存响应丢失再重试原请求。

  通过：阅读器和原草稿保留；保存未知时冻结原标题/正文/引用/request_id，明确重试只产生一篇笔记，不自动重发。


- [ ] **R15 知识点对应PPT页码**

  操作：在专用总结的知识点页码导览中逐页回原文；核对连续页与间隔页的显示。

  通过：页码来自当前版本有效引用；1/2/3可显示第1–3页，1/3只能显示第1、3页，不补齐缺少依据的页；未提取图片不冒充已理解。

- [ ] **R16 单知识点整理笔记**

  操作：选择一个知识点的“写知识点笔记”，审阅标签、编辑并明确保存；回原文学习关联查找。

  通过：只保存该知识点内容和自身引用，不混入全文摘要、其他知识点或全文例题/自测；报告和Topic掌握不变，原文能反查同一笔记。

- [ ] **R17 AI笔记标题与原请求保护**

  操作：修改自动生成的资料/知识点标题，空白时检查保存按钮；填写有效标题后保存。开发协作模拟响应丢失时收起重开并明确重试。

  通过：标题1–240字、空白禁存；标题与正文/引用/request_id同冻，未知时不能编辑，重试后仅一篇；已保存标题在知识笔记中一致。



- [ ] **R18 知识点搜索与目录分页**

  操作：在课件总结中按名称、讲解、分组或误区搜索，核对计数；超过8个匹配时翻目录，然后清除筛选。

  通过：每页最多8项，计数真实；无匹配有明确提示，筛选/翻目录不生成新总结或改写笔记，全部知识点仍可访问。

- [ ] **R19 当前阅读页反查知识点**

  操作：勾选跟随当前阅读页，翻原格式PPT或单片段原文页，核对匹配知识点及引用；尝试无法唯一定位的视图。

  通过：按真实有效引用页匹配，翻PPT不重新加载原件；无匹配不表示没有知识，Word排版页/多片段不能冒充来源页，清除筛选可恢复目录。

- [ ] **R20 逐知识点讲解与草稿连续性**

  操作：从目录查看某点讲解，再用上一个/下一个切换；写笔记草稿后返回结果搜索/翻页，再回草稿。

  通过：对应讲解出现且接收键盘焦点，首尾按钮禁用；完整总结与报告草稿仍可用，已有标题/正文/引用不被导航覆盖。

  操作：阅读侧栏切关联笔记，选择一篇预览，再在完整编辑器打开。

  操作：阅读笔记输入未保存理解，切关联页，点击一篇后预览正文；尝试进完整编辑器并取消，切回写作。由开发协助模拟离线/401和隐藏后的迟到响应。

  通过：选择后才读正文，切换保留原编辑区及输入，离开取消有效；登录后明确重试，无自动正文重放，错误不冒充空列表或替换其他版本。

- [ ] **W15 资料到笔记编辑再回原文**

  操作：在阅读侧栏选择来源并保存笔记，进完整编辑器补充保存，再沿引用回到原片段；在隔离课程删除笔记或撤回人工来源后刷新关联。

  通过：笔记/原文UUID与版本一致，编辑和来源均可追溯；撤回/删除不继续计入有效关联，资料与其他笔记不被误删或改写。

- [ ] **Q03 401登录恢复**（不要直接清空日常浏览器存储来模拟；未触发记条件未具备。）

  操作：自然遇到登录过期，或在隔离环境由开发协助让指定请求返回401；以原账户重登。

  通过：草稿保留，不能在重登框偷换账户；保存/上传/导出/模型请求不因重登自动重放。

- [ ] **Q05 课程删除与撤权**（收尾项，不删除日常课程。）

  通过：错误名称不可确认；正确删除后相应来源不可读/不可检索，其他课程保留，不能拿旧URL绕过；无课程回到明确空态。

### 保留的能力边界

- 关键词检索不是语义检索；版本对照不是自动语义/版式对齐。
- 人工补录不是M1自动OCR；原格式可读不等于复杂动画/图表与PowerPoint完全一致。
- 阅读位置、书签、常用视图、外观及本机草稿副本是浏览器能力，不是跨设备同步或完整账户备份内容。
- 当前题型是选择题/解答题，本地题库显式抽题；不验收已停用的AI生成新题/笔记AI整理。
- 计划完成与掌握状态独立，关联数/题目数不代表学科掌握或可抽资格；不要求自动生成复习计划。
- 整课程资料包与选择包均不是账户恢复包；完整恢复保留业务UUID，因此同库源对象仍在时应拒绝冲突。
- 现有145页PPT原件可完整原格式翻阅，旧不可变解析仅144片段、缺第59页的覆盖差异见[排版实测](learning_layout_acceptance.md)。不能用排版通过替代解析覆盖核对，也不能自动改写旧引用。
- WebKit自动测试、模拟手机视口、真人Safari/iPhone/Windows体验是不同证据。121项勾选也不能自动替四位成员正式签收或把40任务全部标Done。
