## 本轮可以使用

- 原文片段下「添加书签」→核对短名称→保存。阅读桌面「阅读书签」可搜索、分页、改名、移除或回到原文。同版本同片段去重；固定历史版本，缺失/撤权显示错误并保留书签，不回退最新版本或整份资料。
- 每账户UUID/课程独立，auth/me确认身份后读取；最多100条/128KiB，严格字段/重复/UTC时间校验，保存前读取当前存储，storage事件更新。无正文/凭据缓存；未知结构或配额失败明确提示且不假成功。仅当前浏览器，不随账户备份、不同步设备，不保证跨窗口同时写入事务隔离；重要理解仍应保存笔记。
- 同资料至少两份解析成功版本→「版本对照」→选择左右→显式加载。按相同唯一定位精确配对，分类为文本相同/变化/仅左/仅右；重复定位分开列出，格式定位变化有提示。仅文件提取文字，排除人工补录并告知数量，不把页码移动/章节改名猜成语义增删。
- 默认仅变化，可切全部、查找正文/定位、12组翻页，按组展开完整纯文本。桌面双栏，窄屏上下对照；长文本独立滚动且可键盘聚焦，分别回到各自原文。文本不作为HTML执行，不截断来伪称完整对照。
- 弹窗使用统一蓝紫色板、渐变说明卡片、轻量统计和状态标识；延迟结果在切换选择/关闭后失效，错误只显式重试。回源仍经过阅读笔记/资料整理离开保护；成功后焦点指向片段。401让出原生顶层弹窗以便重登，不自动重放操作。
