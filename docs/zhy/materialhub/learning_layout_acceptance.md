## 已有资料的实际基线

用户明确要求使用现有数据测试。通过SQLite只读连接查询当前本机资料元数据，选取一份约4.7MiB的长PPT，原件SHA-256与记录一致，原文件含145页。日常旧解析记录为144个片段；当前解析器在隔离账户导入同一原件得到145个片段。旧记录第59页覆盖差异另记，没有为排版测试回写日常版本或旧引用。

测试只读取原件到内存，再上传至8056临时账户；隔离存储与日常数据库分开，不读取日常登录凭据/笔记正文，不向模型发送资料。私有文件路径、截图和前后指标仅保存在本机忽略目录frontend/local_only/reading-layout-20261023及layout-real-materials.json；仓库不包含该课件。没有私有样例的机器可运行测试内自制80页PPT。

在1440×1000视口、同一原件下，原页面把145个片段及操作卡片一次性展开。Chrome文档高度74594px，WebKit74595px，阅读模块约73123px。这解释了点开PPT后需要长距离滚动的问题，不将其归因于字号或用户资料内容。

## 新布局

1. **PPT优先单页预览**：没有明确引用片段时，打开PPT直接进入本地原格式阅读；就绪后一次定位到幻灯片面板，给固定导航留出顶部空间。阅读区已有操作时不再自动移动，翻页/缩放也不重复跳动。可翻页、输入页码、演示或切换「文本与引用」；引用/书签/历史片段地址仍优先打开对应文本，不被新默认模式覆盖。
2. **文本分页而非裁剪**：PPT文本每页一片段，其他格式每组最多6片段，可按目录或页码跳转。查找仍覆盖整份资料，最后一页、原UUID和完整文字保持。正文在有界区域内滚动，翻页不卸载阅读笔记或改变选区引用规则。
3. **先阅读，再展开工具**：阅读时压缩页面封面并收起概览统计；原格式/PDF模式把引用/问答工具留在「文本与引用」，避免它们占据幻灯片上方。引用笔记卡片按标题/摘录/回跳上下排布，避免手机挤成窄列；课程图片与截图默认折叠但保持挂载，明确截图后会展开反馈；导出/处理记录仍按需展开。
4. **知识点分区**：详情分为「原文依据」「关联笔记」「练习与复习」，一次展示一个面板，切换保留DOM；资料确认时禁用切换。头部和指标缩小，内容区独立滚动；来源摘录保持完整，不再让多条来源、笔记和计划连续把整页推长。
5. **移动目录收拢**：选中知识点后手机目录可收起，仍可展开或「返回知识点列表」。桌面保持目录与内容双栏，按钮/焦点/触控和主题色继续统一。

同源笔记与同名标签候选仍沿既有接口各展示最近6条摘要，页面明确该边界；「打开知识笔记」可进入完整管理。分区只是展示切换，不新增模型请求、作答、复习计划或自动掌握判断。
