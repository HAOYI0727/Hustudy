## 新增能力

资料阅读工具栏「学习关联」查当前版本，文本片段「查看这段关联」仅查该片段。弹窗展示已保存、具有有效逐字引用的知识笔记、资料问答、学习报告和知识点，支持类型/标题筛选、真实计数、每页12条与刷新。列表只读元数据，打开具体成果才进入原模块；同名但无引用的记录不会混入，旧版引用不会自动转到新版。

知识点卡片的「设置练习」仅带入原知识点标签，用户仍需明确抽题、审阅和开始作答。没有已确认题目时如实提示不足；原有进行中作答的恢复、提交幂等和答案权限继续由M4处理。闭环由四个模块的原有实体完成，不另建一套学习记录或自动生成内容。

弹窗沿用全站当前主色、同色浅底与边线、图标和轻阴影；桌面双列、手机单列，标题13–16px，沿用Times New Roman及中文黑/宋/楷角色。320/390/1440宽度、44px触控、Escape返回触发点、原生选择降级与首次离线局部重试纳入验证。原文、编辑器和Office/PDF不随弹窗卸载或重染。

## 核对边界与异常

| 体验 | 正确结果 |
| --- | --- |
| 同名笔记不加引用；同笔记引用多个本版本片段 | 前者不显示；后者只显示一条，不重复计数 |
| 查整版本，再查一个没有对应引用的片段 | 后者为空，明确显示当前片段范围，不回退全版本 |
| 给资料上传新版，在新版打开关联 | 不继承旧版关联；回旧版仍能查看旧版成果 |
| 删除笔记/移入回收站、合并或删除知识点、撤回人工补录后刷新 | 相应对象或失效引用不计入；原业务记录不会被GET改写 |
| 筛选类型/查找标题/下一页/刷新 | 标题是字面匹配，真实服务端分页；空页可回第一页，不用已加载数量冒充总数 |
| 断网首次打开、503、关闭后迟到、401重登 | 局部错误可显式重试；关闭取消读取，迟到响应无效；401让出重登，重登后不自动重开/重放 |
| 资料整理或阅读笔记尚未保存，打开关联并尝试跳转，再取消离开 | 保留原输入和编辑DOM；阅读与整理草稿均验证，不以重新挂载恢复输入代替原会话保护 |
| 另一账户/其他课程片段、独立题库原件或已删除资料URL | 服务端拒绝，不靠前端隐藏；片段不属于该版本时404 |

## 实现与验证证据

新增只读GET `/api/v1/versions/{version_id}/learning-links`，同一读快照内授权，四类SQL适配按updated_at/kind/id稳定排序并分页。SQL内核对引用版本、片段及逐字摘录，人工来源仅CONFIRMED/SUPERSEDED；JSON摘录必须是非空白字符串，数字/布尔值不得被SQLite强制转换为有效引用。响应不含笔记/AI正文、题干/答案、摘录、文件路径或模型配置。旧AI结果没有受支持顶层引用时不猜测嵌套结构。

不新增表、迁移、依赖、后台任务，不改原正文、题库、成绩或引用；前端复用共享transport、Dialog和原UUID路由，AbortSignal与响应范围复核防止旧范围覆盖。每条关联仅保证至少一条当前有效依据，其余来源仍由详情核对；记录数不表示掌握度或可抽题数。
