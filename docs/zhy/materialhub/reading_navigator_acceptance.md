## 如何核对“当前页”

仅接受当前版本、当前显示模式与已就绪阅读器返回的有效正整数页号。原格式PPT使用真实幻灯片页，PPT兼容PDF按已有slide来源关系，原PDF使用PDF页。文本视图只有本页恰好显示一个有效slide/page片段时才能唯一对应；使用真实locator数值，不用片段序号猜页（例如缺页后第58项可以仍是第59页）。

DOCX浏览器排版页/兼容PDF预览页不当作DOCX原始引用页；多个文本片段、未知/异常定位、过期版本或刚加载的阅读器均显示无法唯一定位。开启跟随时若无法核对，不退回全目录伪装筛选成功，提示取消或切到可定位视图。没有匹配只说明现有报告没有该页的有效引用，不等于没有知识、已经掌握或AI已完整覆盖。

目录筛选是当前报告内的视图状态；切到另一个报告/版本重置，当前草稿沿原离开/替换保护。长PPT每个批次独立目录与讲解，不跨批去重或假称融合全文。真实总结质量仍依赖本人核对。

## 人工体验

1. 打开已有总结的PPT→AI阅读助手→知识点与结果，或本人核对预览后生成。原文、总结和当前版本保持一致。
2. 在“搜索课件知识点”输入名称、讲解中的词、分组或误区，核对目录计数。超过8个匹配时翻目录；清除后恢复全部，讲解不因清除而丢失。
3. 点击某项“查看讲解”，应定位并聚焦对应知识点。上一个/下一个正常切换，首尾按钮禁用；键盘操作可见焦点。
4. 勾选“跟随当前阅读页筛选知识点”，翻原格式PPT到另一页，核对目录只列该页有效引用。清除筛选恢复目录。切文本并翻到单片段页，应对应真实来源页。
5. 找一个没有匹配的页或关键词，确认是明确空态而不是提示该页没有知识；Word排版页等不可核对场景不应凭空给出来源页。
6. 整理知识点笔记，编辑标题/正文，返回结果搜索或翻页，再回“笔记草稿”，内容仍在。明确保存后，在知识笔记和原文学习关联核对同一篇及引用。
