## 实际体验步骤

先在新建测试课程中，按[学习关联7步](source_connections_acceptance.md)导入自制[source_connections_demo.md](../../../fixtures/source_connections_demo.md)，确认题库并做错一道题。不需要远程模型。使用专用课程和自制内容，避免混用日常课件/笔记测试移出或删除。

| 步骤 | 入口与操作 | 应看到的结果 |
| --- | --- | --- |
| 1 | 回资料阅读，打开「学习关联」，选择「相关错题」 | 显示原试卷名称、待掌握、来源依据；关联列表不展示题干/标准答案 |
| 2 | 点「错题与复习」；刷新页面 | 标题「错题回顾与复习」，可以看原题、核对原文来源和安排日期；没有自动开始重做，需点击「重做错题」 |
| 3 | 在「安排错题复习」明确选择日期并保存 | 创建计划；已有待办时保留原计划，去错题库下方「复习计划」可改期 |
| 4 | 返回资料，重新打开关联或点击「刷新关联」 | 看见最新待办数与最早日期；账户时区下今日/逾期计划显示数量，未来计划不计入到期 |
| 5 | 打开错题库下方计划，改为未来日期并保存，再回原文查关联 | 最早日期更新，到期数量按新日期变化；原试卷、成绩和掌握状态不因改期改变 |
| 6 | 完成复习计划，再回原文刷新 | 待办减少；如果尚未重做答对，仍为待掌握，完成计划不代替正确作答 |
| 7 | 再进入回看页，明确点重做，答对后「继续保留」 | 关联卡显示「已掌握 · 保留复习」；可继续原文阅读、补充理解笔记和安排下一次计划 |

如在第7步选择移出错题库，再回原文刷新后，该错题不再列出。首次练习成绩和原作答仍保留。界面仅提供已有M4掌握判断的摘要，不把记录数或计划完成率当作学习掌握评估。

## 来源与边界核对

| 情况 | 正确行为 |
| --- | --- |
| 错题快照有本版本/片段的有效逐字引用 | 整版本及对应片段均可查到，标「有逐字原文依据」；多条相同依据只列一次 |
| 历史题只有明确source_version_id，没有引用或引用为空数组 | 仅整版本可列，标「题库版本来源 · 未定位片段」；不冒充某段原文依据 |
| 已有引用是假摘录、片段错配、不支持结构或人工补录已撤回 | 不因source_version_id仍存在而降级成整版本有效来源 |
| 上传新版或删除资料 | 新版不继承旧错题来源；删除资料后原关联接口拒绝，原作答历史按原模块保持 |
| 笔记或试卷同名但来源不同 | 不用名称猜关联；标题查找仅用于筛选已经匹配的记录 |
| 其他账户/课程、已移出错题、其他错题计划 | 不计入本范围；复习摘要只聚合本人当前页错题的PENDING计划 |
| 已完成、未来、今日和逾期计划 | 已完成不计待办；今日/逾期按账户时区统计，页脚显示实际核对日期与时区 |
| 重做答对后再次错题复发 | 复用M4原事件顺序重新判断，复发后不保留过期的已掌握结论；不支持的判断时间显示需核对 |
| 未保存阅读笔记后跳转，取消离开 | 保留原输入与DOM；首次断网局部重试，不清空当前阅读与笔记 |
