本轮选择第一项，是因为原页、图表和公式已经真实存在，截图可以在不引入 OCR/模型的情况下产生直接价值，同时为后续转录、笔记附件和真题证据准备稳定来源。PDF.js 按需加载和本地字体/解码器避免远程 CDN；不将图像渲染宣称为识别了图中文字。

## 四模块融合约束

- M1 只负责授权、原页、资产与来源身份；不生成解释、不判断真题考点、不直接写笔记正文。
- M3 保留图片嵌入语法和反链关系，消费来源元数据；图片/资料删除显示失效。截图页与 DOCX 正文 block 是不同定位。
- M2/M4 如需图像分析，应另行定义 Provider 发送确认与结构化输出；当前截图没有自动进入模型或检索。
- 源文件、版本、引用和图片不因展示名变化或新版上传而静默改指；完整备份需覆盖这些关系。
