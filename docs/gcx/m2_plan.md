## 当前即可使用的候选接口

- 创建至少一个课程Topic，选择资料版本作为目标章节范围。
- GET `/api/v1/courses/{id}/question-draft-context`读取可选目标和已确认原题摘要；POST同课程`question-drafts/preview`预览，沿用remote-queries确认/状态/取消。
- 支持single_choice、boolean、short_answer及historical、variant、weakness；variant必须选已确认原题；历史模式只按手工设置，自选弱项不虚构成绩。
- GET同课程`question-drafts`读取最近20条，GET `/question-drafts/{id}`读取单条。JSON导出包含参考答案，仅供作者审阅与模块导入，不能直接交给考生页面。
- 无密钥时，可上传原始fixtures/materialhub_demo.md、创建“进程与线程”Topic，用基础难度、非变式模式、最多2题运行固定演示。未知输入返回能力限制，不模拟理解。报告也可运行同一资料的完整固定演示。

## 交给xtc/M4的边界

[公开QuestionDraft JSON Schema](question_draft_schema.json)、[权威契约](../contracts.md)、[实际验收](candidate_acceptance.md)。M2输出包含服务端ID、题干、选项、答案/rubric、分值、解析、Topic、模式、来源、原题参考和draft状态。

M4当前无章节UUID实体，因此chapter_id临时使用所选DocumentVersion UUID，并在结果声明chapter_ref_kind=document_version；这是候选范围，不是已经通过正式蓝图验收的章节。xtc须显式映射到正式蓝图，校验数量/章节配额/总分、复制模型和资料快照，并自行推进试卷审阅状态。不得直接把候选当正式试卷。

旧枚举转换已提供`services/exam_ai_context.to_exam_enums`：boolean→true_false；historical/variant/weakness→history_blueprint/topic_variant/weakness_practice。不改现有M4表或业务状态。原题只读快照只含已确认题干等元数据，不发送原题答案，不宣称其考点映射已确认。候选与目标是否实质匹配仍需审阅。
