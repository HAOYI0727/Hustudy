## 接手必读：两个标签的上游接口仍缺失

**“教师强调”和“已确认真题”只有M2消费、校验和展示逻辑已完成，尚未形成真实网页端到端闭环。接手成员需要补上以下上游写入/查询能力；不能把这两项整体标为已完成。** 没有合法来源时报告继续显示“AI建议”，这是保护措施，不是模型故障。报告设置只保留“补充笔记”，不要恢复教师强调或真题的手动补充表单。

| 标签 | 当前缺失 | 接手责任与完成条件 |
|---|---|---|
| 教师强调 | 阅读页主动标记入口、标记持久化与查询实现；M2 reader尚未注册 | M1/zhy在阅读时让学生对原文片段记录教师强调，支持确认、修改、撤回；为API和worker进程都安装只读reader，向M2返回真实有效记录 |
| 已确认真题 | 明确确认卷子为真题的身份录入/保存入口；普通“题库核验通过”不等于真题身份已确认 | M4/xtc补真题身份确认流程，保存约定元数据，并确认题目到知识点、知识点到课件原文的映射；M2已有查询自动消费，不需要用户在报告页再选真题 |

### M1对接约定

入口：[reading_report_evidence.py](../../backend/app/services/reading_report_evidence.py)的`install_reader(reader)`，reader签名为`reader(db, user_id, course_id, sources)`，返回可迭代的标记记录。这是代码集成点，**不是已经存在的HTTP接口**。需要在API和worker各自初始化时注册，不能仅在某次网页请求中设置。

每条记录须符合`ReadingTeacherMark`：UUID字段`id/user_id/course_id/version_id/chunk_id`，正整数`revision`，`status="active"`，`mark_type="teacher_emphasis"`，`kind`为`key/difficult/exam`，`confirmed=true`，原文摘录`quote`为1–500字，说明`reason`为1–1000字。最多200条；归属、原文位置、确认及撤回以真实存储为准。修改应递增修订，撤回后查询不再返回有效记录。

“教师强调”是学生根据课堂信息记录的强调，不代表平台向教师本人核实；不能扫描课件里的“重点”字样后自动生成事实。M2仅当标记与本次实际发送范围、报告知识点的引用相交时附标签。

### M4对接约定

入口：[exam_report_evidence.py](../../backend/app/services/exam_report_evidence.py)的`confirmed_evidence(...)`。自动查询要求卷的`bank_meta_json`中存在：

```json
{"exam_identity": {"kind": "past_exam", "confirmed": true}}
```

此外仍须卷与题目通过既有核验、题目知识点映射`topic_index.selection_reviewed=true`，并存在有效且经确认的知识点课件引用。身份必须由合法的M4确认流程写入，不能按文件名、年份、模型判断或普通题库确认状态推断。确认/撤回应遵循原有权限、并发修订和历史保护规则，不建议手工改日常数据库测试。

### 接通后的联合验收

1. 同一课程选取已标记的课件片段生成报告，只有引用确实相交的知识点出现“教师强调”；无标记保持AI建议。
2. 确认真题身份及知识点/课件映射，再生成报告，相关知识点出现“已确认真题”；普通练习题库不得触发。
3. 修改/撤回标记、撤销身份或映射、删除来源后，旧预览不能继续派发或复用；历史提示依据变化，不改写生成时快照。
4. 跨账户、跨课程和未发送片段不能触发；API和worker路径都要验证。M2消费方负责联合复验，M1/M4负责上游写入及查询测试。

现有隔离自动测试使用模拟上游记录，只证明M2命中、排除和失效分支有效，**不证明两个上游入口已经存在**。[标签实现与测试](supplements_labels_2026_10_24.md)。

## 接手运行

安装和配置按[启动指南](../setup_guide.md)。在项目根目录打开两个PowerShell终端；下列`python`须指向已安装依赖的解释器。当前电脑完整路径为`E:\Anaconda\python.exe`，其他成员使用自己的解释器路径，不改项目源码。

后端：

```powershell
$env:PYTHONUTF8 = "1"
python -m uvicorn app.main:app --app-dir backend --reload --reload-dir backend/app
```

完整路径写法（二选一）：

```powershell
$env:PYTHONUTF8 = "1"
& 'E:\Anaconda\python.exe' -m uvicorn app.main:app --app-dir backend --reload --reload-dir backend/app
```

前端：

```powershell
npm run dev --prefix frontend
```

打开`http://localhost:5173/`。默认由后端托管worker，不另启动重复worker。升级代码后需重启后端及托管worker、前端刷新；若前端仍显示旧版本，重启开发服务并Ctrl+F5。之后在“API接入”用各自账户保存自己的密钥；密钥不随源码、上传副本或账户备份迁移。个人配置以后保存/清除即时生效，无需重启。
