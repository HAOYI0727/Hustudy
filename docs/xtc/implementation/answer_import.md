# 答案文件匹配录入

用户在上传区选择已有题库和答案文件，预览待发送的题号、题干及答案页后明确确认，后台逐页调用当前账户模型。PDF和图片按原页提供，Markdown及TXT作为原文文本提供。文件与题目都是待分析数据。

模型只匹配原文已有答案，不解题。仅允许返回目标题库题目UUID，匹配不明确或缺失的答案填“略”。同题跨页结果合并供用户预览，整套预览确认后原子填充。已有答案需明确同意覆盖。题目版本变化返回409，旧作答快照保留。图形答案保留原页裁剪，作为授权本地图片写入参考答案。

任务记录保存题目修订、模型配置指纹、原始页和逐页检查点，失败不自动重发，不把部分结果当完成。整套填充包含所有题目，重复确认与采纳幂等，其他账户或课程不可读取和修改。预览与结果仅作为待审核草稿。
