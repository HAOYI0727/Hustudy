## 入口和使用

1. 真题与模拟卷 → 上传与校正题库 → 本地直接上传，选择 ZIP 或多份文件。
2. 待上传列表允许删除单个文件、删除选中的文件；ZIP 先列目录，可勾选/删除内部文件，名称含答案/解析/ans 的成员默认不选。点击“上传选中文件并开始导入”才保存成员到独立题库文件库。ZIP目录检查会将压缩包发送到本机API作校验，不向模型发送；“未上传”指尚未保存成员。
3. 扫描 PDF 等待检测后点击“AI转写原页与公式”，确认原件名称、目的地智谱、glm-4.6v-flash、是否仅题目及是否 AI 归类。图片上传也有“AI视觉转写”选项。共用已配置后端 Key，不修改 M2 全局模型。
4. 公式使用 $...$ / $$...$$ LaTeX，可在题目校正处查看渲染和编辑源码，练习/结果/错题处同样渲染。特殊符号不做 NFKC 替换。原页只用于审核；原页可能含其他题目和答案，不自动当考试插图，仍需裁取并确认。
5. 每页成功保存 checkpoint，失败在识别历史或本批文件行点击“续跑未完成页”。不重发已成功页；配置变化要求重新确认来源。取消/删除原件/撤权/租约失效会阻止后续页发送及迟到结果落库。
6. 选择自动归类时，转写成功后使用当前标签/别名做 GLM-4.7-Flash 语义归类。已有匹配项优先且蓝色高亮；候选不自动建标签，不覆盖人工标签。用户选用并保存，题目仍需审核。词表/题目已变更或超过32题/200标签/24000字符时明确提示分批手动归类。
7. 上传结果行可从批次删除并取消尚未完成识别；已入库题目在下方按题/整份删除；独立题库文件库另有“删除原件”，明确提示来源失效及历史试卷保留。三种动作语义分别说明。

## 识别边界

严格校验 Page/Block JSON，仅采用正文，不保存模型推理。保留大题公共条件与子问，跨页续题必须对应上一题号/题型；未知、重复题号或超预算显式失败。只题目模式拒绝返回 answer/explanation，提示模型剔除后填写答案/批注，无法区分与给定条件时标记待核对。不能依据模型生成的结构证明全部字符正确，尤其扫描表格、公式、手写内容，必须对照原图。

原卷没有标准答案时不补造。选择/填空须补答案/设置唯一性再确认；解答题仅检查提交。AI只负责转写和标签建议，抽题继续使用本地题库。
