# Markdown题库存储与GLM5.3图文处理（2026-10-20）

## 实现与入口

当前题库图像/PDF转写、文本拆题、知识点归类统一使用glm-5.3-flash（项目已有GLM5.3型号）。图像使用Base64 Data URL，并保留JSON结构化输出和thinking.enabled；不再固定使用GLM4.6V/4.7。本机仅替换模型配置行，保留原密钥及其他设置，不输出密钥。新预览记录模型与提示词版本，旧预览/任务不能在切换后静默发送，旧结果保留原模型身份。

新导入和保存的题干、选项、解析、解答题参考答案按Markdown源码持久化在统一SQLite，bank_data.content_format=markdown，无新表/迁移。按原题号拆合也保留此格式，不重写旧试卷/作答快照。Markdown源文件可以下载，不保存未经清洗的模型HTML。

- 明确的TSV（制表符）/矩形“ | ”分列表格、简单HTML table自动转GFM表格；已规范的Markdown原样保留。代码块、独立公式不重排；数学中的竖线不按表格猜拆；单元格竖线转义，空格/空单元格保留。
- 图像表格要求GLM5.3直接在题干原位置输出规范GFM，不用文字概述或遗失占位符。保留LaTeX/特殊字符，不求值、不解题。兼容有界的结构化表格输入并检查列数、占位符、长度。
- HTML合并单元格/复杂结构无法无损转换时保留为可见代码供校正，不猜数据；扫描模糊/截断内容显示明确核对提示。
- 默认展示渲染后的Markdown（GFM表格+KaTeX公式），原始题干不再作为标题代码显示；源码和答案收进“编辑Markdown源码与答案”。识别警告和AI知识点建议保持默认可见；参考解答/解析可展开查看渲染结果。
- “下载题目Markdown”获取已保存题干/选项的UTF-8 .md，未保存时禁止下载，答案/解析不混入题目下载。检查本人/课程/有效来源/当前考试状态，UUID文件名避免路径注入。

## 实际模型迭代

先前GLM4.6V/4.7的1305繁忙记录是历史状态。GLM5.3真实图文请求已成功；初次返回非法JSON，改为图文保留response_format=json_object并明确LaTeX JSON转义后通过。发现下划线数据误当填入答案被删除，修正为保留题干条件中的数据/公式，模糊或归属不明时保留原文并提示，不猜数字；修正版重读首图，保留初次输出供对照。模型表格占位符遗漏后，改为直接GFM输出。

综合题归类曾因4个合法新标签超过旧3项限制失败。候选是可选建议，容量放宽至8，完整显示、不截断、不自动建标签；已有标签仍优先，重复/越界/遗漏题目仍严格拒绝。版本v3纳入预览指纹。当前实际ZIP处理与验收结果见下方最终记录，不把模拟测试当真实质量。
