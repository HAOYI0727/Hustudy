## 试用任务

由团队实际邀请至少5位目标用户，以匿名编号记录。准备一门课程的自制/获授权讲义、至少3份年份/分值/答案包含未知值的题库，含重复材料、跨块题与多空。不得向参与者预先代操作，失败也要记录。

1. 建课、上传题库，对照来源检查识别与四选项；设置填空唯一性、标签和主标签，校正/拆合并确认。
2. 设置年份/卷别和重复代表卷；生成统计，人工复算涉及题数、不同年份分母与主标签分值；改名/合并后重算STALE报告。
3. 对照资料候选并确认来源，查看相关笔记、图片和“尚未评测”；不能把未匹配当成课程未讲授。
4. 在AI学习练习页按标签抽题，检查四选项重排、保存、刷新恢复、交卷；唯一填空自动判、非唯一填空自评、解答只检查提交。
5. 回看错题、建立复习任务、重新安排日期；提交问题类型、文字和可选评分。

沿用需求NFR-09目标：至少4/5独立完成规定闭环，易用性平均≥4/5；这些是待测阈值，不能由代码测试替代。原NFR-13真实AI新题指标因用户将来源改成题库不适用于本地抽题，不能用随机抽题声称通过AI新题质量指标。

## 8分钟演示脚本

- 0:00–1:00：课程和用户题库来源，上传自制question_bank_demo.md。
- 1:00–2:00：识别/人工校正、唯一填空、多空与解答的不同规则，演示缺答案不能确认。
- 2:00–3:00：拆分/合并后父题不计分、标签主次、年份未知和重复材料代表卷。
- 3:00–4:00：统计分母、改名后STALE、资料/笔记/图片候选和未知掌握状态。
- 4:00–6:00：确认蓝图或标签随机抽题，核对选项重排，保存/刷新恢复/交卷与分类处理。
- 6:00–7:00：错题回源、复习改期、反馈类型/评分。
- 7:00–8:00：说明不调用模型生成练习、识别/平台测试边界、展示真实自动测试与待做的真人验收。
