# PDF、ZIP与免费模型结构化识别验收

日期：2026-10-20。承接用户本机PDF无法出题、识别后立即展示、ZIP导入及免费模型接口要求。未提交/推送；保留此前工作区修改；没有复制用户PDF进公开fixtures，没有真实模型调用。

## 原因与修复

旧页面只上传到M1，还需再点“识别已上传题库”；旧规则只认普通题号和答案标签，无法区分“题目N分组→组内重编号→无答案标签的参考解答”。本轮保留M1原格式解析与Citation，对上传后的解析/索引状态自动轮询，就绪即拆题、聚焦当前题库、展开并滚动到题目区；无需再次点击识别。失败逐文件显示，可显式重试，已完成项不丢。已有资料的手动导入入口仍可用。

用户指定PDF为3页，可提取文本。实际导入17道解答小题，保留1-1至1-3、2-1至2-11、3-1至3-3；组内自然排序，跨页2-8和3-2的原文解答完整。题干与提供的参考解答分开，原答案不做事实修正、AI评分或补造。审核可编辑参考解答，提交后可查看；解答题仍只检查提交。无标签分离使用明确分组与问句/指令终止行，显示需人工核对提示，不宣称任意版式都准确。

解析器版本bank-rules-v3。原文相同且已用v3导入则返回已有题库；旧v2导入可重新识别为新草稿，旧样本标记新版本为代表卷并增加metadata revision，原题与旧作答保留，不覆盖快照。GET题库新增paper_id过滤，避免新导入题目被旧分页遮住。

## ZIP

支持PDF、PPTX、DOCX、MD/Markdown、TXT、PNG/JPEG/WebP；按自然文件名顺序经M1逐条保存，文档自动解析入题库，结果显示成功/失败/跳过及原因。图片只进入待选择队列，保持文档处理页；点击查看ZIP图片后选择是否OCR，不自动联网或做OCR。嵌套目录仅用于文件列表显示，服务器从不按成员路径解压写盘。

预检50MiB压缩/128MiB总解压/32MiB单文档/10MiB单图、200项总目录与文件、40有效文件、20图、压缩比200。拒绝绝对/盘符/父目录/重复大小写路径、符号链接、加密、嵌套压缩及异常尺寸/CRC；全部预检后才开始保存。系统杂项和不支持的类型明确跳过。ZIP可部分成功，失败不得冒记完成；重试为用户显式操作，文档原件由M1按hash复用。

## AI识别

已核对智谱[GLM-4.7-Flash官方页](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)、[免费发布公告](https://www.zhipuai.cn/zh/news/148)及[对话接口](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)。固定使用glm-4.7-flash及官方chat/completions，不回退到付费模型；账户访问权限/限流/免费政策以平台为准，不承诺无额度限制。该模型是文本输入，图片仍经显式本地OCR；不宣称直接视觉理解。

M4通过M2现有ZhipuProvider.structured公开接口请求JSON。AI只返回原文行号及题型，题干/选项/解答/解析由服务器取回原文；非法/重复/越界行号、多个原题合并为一题、遗漏原题都拒绝，不把任意聊天文本当题目。结构化接口实际返回(model,usage)元组，已用MockTransport覆盖HTTP契约。默认每次16,000字符/40块/32题、8192输出tokens，完整范围超限即拒绝，不截断。

用户先选AI识别，文档就绪后显示完整原文、端点、固定模型和15分钟预览，明确确认才生成BANK_EXTRACT单次任务；拒绝不发送，超时/429/坏结构不自动重发。来源删除或配置变化时阻止派发/迟到入库，预览不再返回已撤回原文；目录元数据不暴露内部来源和配置指纹。M4任务与M2 AI_ANALYSIS共享并发闸门；未改问答/报告的模型选择。原文和任务快照随账户备份校验、恢复，无新迁移。

**本机实际配置为mock，API Key未配置。** 本轮完成接口集成与确定性模拟验证，不宣称真实AI请求成功。用户可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/configure_zhipu.py --model glm-4.7-flash
```

在本机隐藏输入密钥，不要发送到聊天或前端。配置后重启API与worker，页面“识别方式”中启用AI结构化识别；预览确认发送后完成会自动展示。尚未配置时AI选项禁用，本地PDF/ZIP识别可直接使用。
