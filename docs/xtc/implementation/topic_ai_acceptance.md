# M4 AI知识点语义归类（2026-10-20）

用户反馈短语索引准确度不足，本版替代 M4-TOPIC-INDEX-01。导入与题库列表不再计算本地短语建议或据此分配标签，旧人工/导入标签保留。

## API接入入口

题库页面“上传自己的题库”中，展开“API接入与模型配置”，可见配置状态、平台地址、命令和重启说明。根目录 `configure_ai.cmd` 可双击启动隐藏密钥输入；等价命令：

```powershell
.\.venv\Scripts\python.exe scripts/configure_zhipu.py --model glm-4.7-flash
```

在终端输入从智谱平台获取的API Key，保存在本机后端 `.env`，重启 API/worker 并刷新页面。不要在聊天或网页正文中粘贴密钥。此配置与AI学习、题库AI拆题共用，脚本会将共用模型设为 glm-4.7-flash。

知识点归类固定复用 `ZhipuProvider`、`glm-4.7-flash` 与 `https://open.bigmodel.cn/api/paas/v4/chat/completions`，不切换收费模型。[官方模型/JSON接口说明](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)。平台额度和政策以官方为准。

## 使用

1. 上传 PDF、ZIP 或识别图片，题目正常拆分显示。
2. 在“题库审核与确认”选择“AI归类这N题”。优先处理本页勾选题目，否则处理本页尚未归类题目，每批最多32题；超过一批时，完成后继续下一批，切页处理剩余题目。重新归类已有建议时先勾选题目。
3. 核对将发送的题干、选项及当前课程标签/别名，点击“确认发送并AI归类”。不发送参考答案、解析、原始PDF或图片。
4. 完成后已有标签建议靠前并蓝色高亮，显示语义依据。点击“选用AI推荐标签”，或手动勾选，然后保存本题校正；主标签仍可调整。
5. 没有合适已有标签时显示AI新标签备选，点击才创建并选中，保存本题关联。确认题库后按标签抽题。

## 契约和限制

- 三个接口：`POST /past-papers/{id}/topic-ai-preview` 接收 `question_ids`；`GET` 同路径读取预览/任务；`POST /past-papers/{id}/topic-ai-confirm` 接收 `confirm_remote_send:true` 和本次 `preview_id`。
- 单批最多32题、200个已有标签、题干/选项/词表合计24000字符；15分钟预览有效期。超限明确失败，不截断。任务持久化为 BANK_EXTRACT，复用全局AI单并发与180秒租约，实际Provider单次调用预算不变，不自动重试。
- AI必须完整覆盖输入题目，只能选当前词表ID，每题最多8个已有标签/3个新标签备选，每个备选最多32字符；重复、越界、不完整输出整批拒绝。返回同名已有标签时规范化回已有ID，歧义拒绝。
- 模型建议不自动覆盖人工标签，备选不自动创建。建议写入bank_data并增加revision，题库转草稿；旧模拟试卷/作答快照不改变。修改题干/选项清除旧建议，修改标签选择保留建议。
- 确认和调用前后验证配置、题目revision、全部词表快照与来源授权；跨窗口替换预览会因preview_id不同而拒绝，取消或丢失租约不能写回。
- 未保存编辑时禁止发起分类；AI完成时检测草稿，避免自动刷新丢失输入，可保存后点击“载入AI建议”。重新进入页面可继续查看任务。
- 缺少密钥时禁用AI按钮，明确引导本地配置；普通上传、人工分类和抽题继续可用，不用短语结果伪装AI。

本轮只做模拟Provider/浏览器模拟响应及实际本地文件解析验证，没有使用真实密钥调用模型，因此不宣称模型分类准确率已经验证。无新增依赖或迁移，不提交推送。
