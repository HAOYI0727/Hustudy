# M4 知识点自动索引（2026-10-20）

> 历史实现记录：用户反馈准确度不足，已由 [AI语义归类](topic_ai_acceptance.md) 替代，短语自动推荐/分配已停用。以下保留当时的实现和验证记录。

已实现本地索引，无需模型密钥或外部请求。PDF/ZIP/普通文档、手动粘贴、图片 OCR 和 AI 拆题结果共用导入逻辑。仅使用题干，不使用参考答案来推断知识点。

## 使用

1. 在课程内添加知识标签及别名，例如“队头阻塞”，别名“HOL”。
2. 上传题库，题干含 HOL 的题目会自动勾选“队头阻塞”，仍保持待审核。
3. 在“知识点归类”查看蓝色推荐，已有匹配排在最前，显示依据。可以取消、增加标签，设置主标签后保存本题。
4. 无明确匹配时展示题干短语备选，例如“简述虚拟内存的作用”得到“虚拟内存”。点击“＋ 虚拟内存”创建并选中，或输入修改后的名字创建，随后保存本题校正。
5. 确认题库后，按这些知识点筛选和抽题。

## 行为边界

- 优先名称/别名，长且明确的命中优先；英文不做词内子串匹配，TCP 不会匹配 HTTP 或 TCPIP。合并前名称和别名映射到当前标签。
- 没有人工默认/原文标签且唯一最明确的名称匹配时，才自动设置新草稿主标签。歧义匹配不自动选择，已有用户标签不覆盖。
- 从同课程最多2000道已确认题目参考关键词，按有界加权集合相似排序，仅推荐，不自动套用，也不展示正确概率。
- 无名称命中时从原题短语提出最多3个候选，并非模型语义理解；复杂跨术语题可能无合适推荐，可人工选择或新建。最多返回8个已有推荐。
- 候选不预先创建；点击后标签加入词表，本题关联仍需保存。创建期间保护当前编辑草稿，失败显示原因，不自动重试。
- 题目列表读取时刷新推荐；修改题干需先保存再获得新建议。只读推荐不修改旧题、旧试卷或旧作答。人工编辑清除旧自动分配标记。
- 不增加依赖、数据库迁移或真实模型调用；不提交/推送。

## 实测

- 新增8个后端风险测试：明确名称/别名自动分配与默认保留、跨用户/课程隔离、不根据答案匹配、候选不污染词表、英文边界与规范化、别名歧义、已确认样本推荐/排除自身、合并与修改后刷新、同批新标签复用、索引只读。
- 新增2个 Chromium 浏览器用例：真实文件上传后自动选中/排序/高亮，修改题干后刷新；新候选点击创建、保留正文、保存关联、390px不溢出。
- 同轮 PDF/ZIP 浏览器回归包含用户授权的本地 `6-ans.pdf`，实际拆分17题并检查跨页解答。私人文件与截图仅在本地，不纳入仓库。
- 浏览器5项通过（2项新增+3项PDF/ZIP），前端58个测试通过，TypeScript检查、Ruff检查、生产构建通过。
- 后端最终相关回归58项通过，包含新增8项及真实PDF、ZIP、图片导入、统计、模拟作答和AI学习本地抽题；仅存在既有Starlette弃用提示。

隔离测试结果不代表真人试用或任意学科语义准确率；用户仍需核对题目与标签。
