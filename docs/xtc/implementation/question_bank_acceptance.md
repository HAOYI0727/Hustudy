## 已实现的代码闭环

1. **导入与校正**：复用M1上传/解析PPTX、PDF、DOCX、Markdown，或选择已有资料/已确认人工转录、粘贴正文。规则识别选择、填空、解答，分离A–D及答案/解析/知识标签；缺失不猜。校正有revision冲突保护，全部有效后确认。
2. **拆题与样本**：同卷原子拆分/合并；旧题SUPERSEDED保留历史并退出确认/计分，子题分值未知不分摊父总分。原始文件/文本hash重复返回原身份；不同材料可人工设置重复代表卷，防止同年同卷重复计样本。年份未知可空，卷别与来源可校正。
3. **考点与关系**：稳定Topic UUID、改名/别名/合并、旧ID重定向；导入别名归一，歧义明确拒绝。主标签用于分值、次标签只算涉及。M1资料、M3笔记、M1图片元数据经已有只读适配器形成候选矩阵，人工对照原文后确认资料引用；未匹配不等于未讲授，未判定作答为unknown。
4. **统计快照**：已确认独立样本/叶子题/标签，保存输入样本hash、修订、算法及分母。未知年份/分值单列，空分母null；题目/映射/标签/样本决定/确认来源改变后旧报告STALE，重算创建新快照，不覆盖历史。至少三份自制样卷的确定性分母/主次分值已复算测试。
5. **蓝图与随机练习**：AI学习练习页和M4共用用户题库，匹配任一所选标签，不调用模型；四选项随机重排且同步正确键。独立题型/标签配额使用整数最大流匹配，避免贪心或人为预设类型×标签。题量不足明确失败；请求UUID重试返回同一草稿。
6. **作答与分类处理**：DRAFT审阅→REVIEWED→READY，冻结题目/顺序/时长；逐题保存、刷新恢复、服务端截止、提交幂等。有完整标准答案的选择题与唯一填空自动计分；唯一填空保存后返回对错，逐空NFKC/首尾空白规范化、区分大小写。非唯一填空交卷后显示参考答案，由用户自评；解答默认只检查提交，可由用户自评正误，不自动判分。自动分母不含自评/解答。
7. **错题、复习和反馈**：同作答题目错误事件不重复，手动错题待办重试返回已有，日期按账户时区，支持完成和冲突受控改期。反馈有类型、文字、可选评分，时间由服务器生成。历史练习和作答可回看。
8. **兼容与安全**：考生DTO白名单，进行中禁止答案/审阅/题库管理旁路；归属/课程撤权与来源校验。0019/0020增量迁移及账户包0020，显式兼容0012–0019旧包，快照、自评、合并、统计报告往返和课程清理适配。新AI练习preview/demo返回410，旧确认/旧队列派发阻断，历史候选仍可读；资料问答/学习报告保持。

## 2026-10-21 非空标签删除与未自动判分题自评
标签选中后在“管理”的独立删除区域操作，包含题目、来源或子标签时也可删除。仅移除当前有效题目上的该标签关联，保留其他标签；无剩余标签的题目在“考点、统计与蓝图→未归类”查看。子标签提升到被删标签原上级，历史试卷、作答及旧题快照不重写。删除元数据保留用于备份/历史引用，被删标签不会被AI归类或搜索重新选中；同名可新建。活动作答期间仍禁止整理标签。

无标签题可从全课程练习抽取。题型和四个选项仍需核验；填空唯一性仍需明确设置，缺标准答案不会由系统推断。缺答案的选择/填空、非唯一填空及解答题，在交卷后的每题下方都有“我答对了 / 我答错了”，已有完成练习也可使用。自评错误幂等进入错题库，刷新保留；自评不计入自动分数，也不覆盖已自动批改结果。判断后按钮禁用，重复相同请求可返回，冲突拒绝。全卷无自动判分题时显示说明，不展示误导性的0/0自动分数。
